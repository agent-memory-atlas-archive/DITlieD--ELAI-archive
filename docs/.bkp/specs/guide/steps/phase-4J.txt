GOAL
Connect elai_cc to the Empire ecosystem. elai_cc speaks the FactoryLine protocol,
registers as a brain, subscribes to Empire events (live GRC/SSB data source),
exposes its capabilities back to Empire as a neuron, and replaces the broken
brainctl CLI. Empire gains self-improvement, grounded reasoning, and pipeline
execution. elai_cc gains a live deployment environment and multi-brain coordination.

Empire architecture (verified from source, empire.txt section 1):
  Engine hierarchy: EngineMKI -> EngineMKII -> EngineMKIII (inheritance).
  Two bus layers: IPC engine socket (/tmp/brain-engine.sock, module-to-engine)
    + FactoryLine control socket (/tmp/brain-factory.sock, factory-to-brain).
  Both: newline-delimited JSON over AF_UNIX SOCK_STREAM.
  Brain = deployment unit (brain.json manifest). Neuron = module registered to brain.
  HookRegistry (route|event hooks), BusRegistry (fnmatch pattern subscriptions).
  FSB binary transport: 12-byte header (frame_id:u32, part_idx:u16, part_total:u16, payload_len:u32).

What is solid in Empire (leverage, verified 2026-04-08):
  IPC layer (src/lib/ipc.py): pure stdlib, tested. Max 65536 bytes. Event format:
    {type, agent, channel, payload, timestamp, mac, ip}.
  FactoryLine bus (src/core/bus.py): pure stdlib, tested. Protocol "v":1. Command format:
    {cmd: register|heartbeat|list|request_update, v, brain, dir, pid, ts}.
  HookRegistry: route|event kinds, reserved paths, conflict detection.
  BusRegistry: named buses, fnmatch pattern subscriptions, dedup dispatch.
  Multi-brain isolation: tested (3 test classes: separate dbs, hooks, neurons, buses).
  FSB binary transport: clean framing (12-byte header, 256KB max frame).
  SmartCatalog: recursive discovery, manifest validation, unlimited depth.
  Engine handler types (MKI): REGISTER_HOOK, EMIT, QUERY_HOOKS, SUBSCRIBE, UNSUBSCRIBE,
    BUS_CREATE, BUS_JOIN, BUS_LEAVE, BUS_LIST. MKII adds persistence. MKIII adds WS.
What is broken (fix via 4J.6, verified 2026-04-08):
  brainctl<->brain_lifecycle circular dep (lazy imports in both directions).
  EngineMKII hard-imports slc at module level (try/except fallback disables HTTP).
  unique-factory/types directory shadows stdlib types module.
  (3 issues only. Previously listed _send_event stub, ECS dynamic imports, workforce
  lambdas were incorrect -- see empire.txt section 2 for correction log.)
What is dead code (supersede, not integrate, verified 2026-04-08):
  workforce/assembly/runtime/actions.py (7 lines, all lambda: None stubs).
  brain.json (no schema validation -- PipelineSpec supersedes with 6 enforcement layers).
  (MetricsStore and SeedState are ALIVE and used. InternAgent does not exist.
  See empire.txt sections 6-7 for correction log.)

RISKS TO WATCH
  R-NEW-1: Transport portability. Empire uses AF_UNIX sockets (Linux only).
    elai_cc develops on Windows. Need transport abstraction: UnixStream (Linux prod),
    TcpStream (Windows dev / remote), with protocol parity.
    Mitigation: trait FactoryLineTransport abstracts socket type. Protocol tests run
    over both transports. Wire format identical (newline-JSON).
  R-NEW-2: Protocol drift. Empire's FactoryLine protocol has no formal spec beyond
    the Python source. If Empire changes wire format, elai_cc breaks silently.
    Mitigation: contract tests deserialize real Empire messages (captured fixtures).
    Canary health check on connect verifies protocol version.
  R-NEW-3: Circular dependency injection. Importing brainctl in Empire triggers
    lazy-import chains that fail. elai_cc must NOT import or depend on brainctl.
    elai_cc drives FactoryLine directly, bypassing brainctl entirely.
    Mitigation: zero Python imports from Empire. Pure Rust FactoryLine client.
  R-NEW-4: Empire event flood. Empire buses use fnmatch pattern subscriptions.
    Subscribing to "factory:*" on a busy deployment could flood SSB with events.
    Mitigation: rate limiter on bridge (configurable events/sec cap), SSB write
    batching, event priority classification (action_type filtering).
  R-NEW-5: Bidirectional trust. When elai_cc registers as a neuron (step 5),
    Empire can invoke elai_cc capabilities. Untrusted Empire commands must not
    bypass Tier C isolation or evidence gates.
    Mitigation: all Empire-originated requests enter through IPC proxy with
    ToolFilter whitelist. Empire cannot trigger FSM transitions or bypass gates.
