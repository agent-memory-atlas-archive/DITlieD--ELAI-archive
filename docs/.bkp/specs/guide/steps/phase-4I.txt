PHASE 4I: MEDIA VALIDATOR (conditional) -- IMPROVED 2026-04-06
Prerequisites: Phase 4A complete (agent process isolation operational)
Condition: only implement if pipeline tasks produce media outputs.

SCOPE: see docs/specs/guide/implementation-guide.txt

GOAL
Validate non-code outputs (images, 3D models, audio, UI screenshots).
Tier 1 deterministic checks (CPU, <100ms) + Tier 2 VLM structured output (GPU, ~2-5s).
Only loaded when PipelineSpec contains media-producing steps.
Tier 1 has veto power over Tier 2 in all cases.

RISKS TO WATCH
  R15: VLM accuracy. VLM is ADVISORY only, Tier 1 has veto.
       VLM disagrees with Tier 1 -> flag for human review, never auto-override.
  R-NEW-1: External tool availability. Tier 1 depends on ImageMagick, FFmpeg, Tesseract,
       Blender CLI. If any missing at runtime, validation silently degrades or panics.
       Mitigation: PRE_GATE availability check + graceful per-tool capability flags.
  R-NEW-2: GPU swap cost. Mode B (InternVL3.5-38B) requires full GPU swap (~30-60s).
       Mitigation: batch media validations, only swap once per phase boundary.
  R-NEW-3: SGLang dependency for Mode B. InternVL3.5-38B MUST use SGLang
       (RadixAttention for sequential image KV cache). Ollama/vLLM will OOM on
       multi-image sequences. Mitigation: PRE_GATE checks SGLang availability for Mode B.
  R-NEW-4: MoE VRAM misconception. Qwen3.5-VL-30B-A3B is MoE with ~3B active params,
       but ALL 30B params are stored in VRAM. 8-bit = ~30GB, Q4_K_M = ~17GB.
       Does NOT fit alongside other models on a single GPU.
       Phase 0 (RTX 3060 12GB): cannot run ANY VLM mode. Mock VLM only.
       Production (2x RTX 3090 48GB total): Mode A Q4 on one GPU (~17GB), Mode B on both.
       Mitigation: hardware guard in VlmProcessConfig, mock VLM for CI/Phase 0.
  R-NEW-5: SSIM/LPIPS floating-point non-determinism. f64 SIMD (FMA/AVX2) is not
       bit-exact across platforms. ONNX Runtime GPU kernels (cuDNN) are non-deterministic
       (ORT issues #4611, #22818). Mitigation: CPU Execution Provider only for
       SSIM/LPIPS, epsilon tolerance (1e-6) instead of bit-exact comparison.
