SOLID PRINCIPLE ENFORCEMENT:

Single Responsibility Principle (SRP):
Rule Definition: "Each module should have one reason to change"
Anti-Pattern: "Prevent combining UI rendering, database queries, and input validation in single component"
Implementation: Separate concerns into distinct classes with focused responsibilities

Open/Closed Principle (OCP):
Rule Definition: "Software entities should be open for extension, closed for modification"
Anti-Pattern: "Avoid modifying core validated algorithms for new features"
Implementation: Use abstract interfaces and dependency injection

Liskov Substitution Principle (LSP):
Rule Definition: "Subtypes must be substitutable for their base types"
Anti-Pattern: "Subclasses throwing errors not defined by parent"
Implementation: Strengthen parent behaviors, maintain interface contracts

Interface Segregation Principle (ISP):
Rule Definition: "Clients should not depend on unused interfaces"
Anti-Pattern: "Massive monolithic interfaces out of convenience"
Implementation: Split contracts into granular traits (IWorker → IWorkable + IEatable)

Dependency Inversion Principle (DIP):
Rule Definition: "Depend on abstractions, not concretions"
Anti-Pattern: "High-level modules depending on low-level modules"
Implementation: Use IoC containers, abstract dependencies

IMPLEMENTATION EXAMPLES:

SRP Enforcement:
```yaml
# .claude/rules/architecture.yaml
single_responsibility:
  pattern: "class.*{.*}.*{.*}.*{.*}"
  message: "Class has multiple responsibilities. Separate into focused components."
  severity: "high"
```

LSP Enforcement:
```yaml
liskov_substitution:
  pattern: "override.*throw.*new.*Error"
  message: "Subclass throwing undefined error. LSP violation."
  severity: "critical"
  example: |
    class DraftOrder extends Order {
      markAsPaid() {
        throw new Error("Payment method not available");
      }
    }
```

ISP Enforcement:
```yaml
interface_segregation:
  pattern: "interface.*{.*}.*{.*}.*{.*}.*{.*}"
  message: "Interface too large. Split into focused traits."
  severity: "medium"
  example: |
    # Instead of:
    interface IWorker {
      work(): void;
      eat(): void;
      sleep(): void;
    }
    
    # Use:
    interface IWorkable { work(): void; }
    interface IEatable { eat(): void; }
    interface ISleepable { sleep(): void; }
```

DIP Enforcement:
```yaml
dependency_inversion:
  pattern: "import.*LowLevelModule"
  message: "Direct dependency on low-level module. Use abstraction."
  severity: "high"
  frameworks: ["InversifyJS", "NestJS", "Spring"]
```
