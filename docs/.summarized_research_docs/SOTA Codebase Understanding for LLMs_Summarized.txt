SOTA Codebase Understanding for LLMs - Technical Summary

PERFORMANCE DEGRADATION PROBLEM:
Repository-level tasks vs single-file puzzles:
- 51.50% drop in input prediction accuracy
- 42.15% drop in output prediction accuracy
- Models trained on pre-2024 code, oblivious to modern patterns
- Linear token prediction fails for complex architectures

CORE METHODOLOGIES:

1. DETERMINISTIC AST-DERIVED KNOWLEDGE GRAPHS (DKB)

vs Model-Generated Graphs (LLM-KB):

Performance Comparison:
- Graph Construction Time (Shopizer): 2.81s vs 200.14s
- Graph Construction Time (ThingsBoard): 13.77s vs 883.74s
- Indexing Completeness: 100% vs 68.8% (skipped 377 files)
- Chunk Coverage: 0.902 ratio vs 0.641 ratio
- Multi-Hop Correctness: 15/15 vs 6/15 queries

Critical Failure Mode: Probabilistic indexing incompleteness
- Token limits cause file skipping
- API timeouts during extraction
- Context truncation leads to blind spots

DKB Advantages:
- Mathematically exhaustive extraction
- Compiler-inspired parsing
- Bidirectional graph expansion
- Interface-consumer tracking

2. REPOSITORY INTERACTION GRAPH (RIG)

Build System Integration:
- Maven, Gradle, npm, Cargo, Makefile analysis
- Language-agnostic dependency mapping
- Entry point identification
- Test runner recognition

Performance Metrics:
- Single-language repositories: +6.6% accuracy, +46.1% efficiency
- Multilingual repositories: +17.7% accuracy, +69.5% efficiency

Failure Mode Shift:
- Without RIG: Structural misunderstandings dominate
- With RIG: Pure logic mistakes only
- Eliminates entry point hallucination
- Prevents cross-language dependency errors

3. DETERMINISTIC CONTEXT COMPILERS (AEGIS)

Paradigm Shift:
- Abandons vector math and similarity algorithms
- Uses Directed Acyclic Graph (DAG) with SQLite
- Maps file paths to architectural guidelines
- Model Context Protocol (MCP) server implementation

Query Processing:
```sql
SELECT guidelines FROM architecture_map 
WHERE file_path = 'app/UseCases/Reorder.ts'
```

Benefits:
- Zero vector retrieval
- Deterministic constraint satisfaction
- Instant architectural compliance checking
- SOC2 Type II / HIPAA compliance support

4. DEEP CONTEXT THREADING

Enterprise Monorepo Handling:
- Distinguishes behavioral logic from boilerplate
- Tracks frequently changed files
- Semantic dependency graph mapping
- Cross-repository interdependency identification

Use Cases:
- Massive enterprise refactoring
- Microservice boundary impact analysis
- Token validation signature tracking
- Multi-repository implication awareness

5. CODEBASE-MEMORY MCP SYSTEM

Architecture:
- Zero-dependency graph database
- Neo4j backend with BinQL protocols
- NL2GQL (Natural Language to Graph Query)
- Sub-millisecond query response

Query Examples:
- "Find all controllers using UserService"
- "Identify downstream impact of OrderService changes"
- "List all files dependent on PaymentGateway"

Performance:
- Sub-millisecond query response
- Deterministic result consistency
- No vector similarity computation
- Exact graph traversal algorithms

IMPLEMENTATION ARCHITECTURE:

Graph Construction Pipeline:
1. Parse build system files (pom.xml, package.json, Cargo.toml)
2. Extract AST relationships from source files
3. Map dependencies bidirectionally
4. Store in graph database with metadata
5. Index for fast query execution

Query Processing:
1. Natural language query input
2. NL2GQL translation
3. Graph traversal execution
4. Result aggregation and ranking
5. Context injection into LLM
