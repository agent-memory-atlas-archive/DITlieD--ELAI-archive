# F-12: semantic contradiction pre-filter — deterministic local NLI judge between audit_conflicts Surface and user adjudication (trigger-only, crates/memory)

Objective: close the one real recall gap between ELAI's deterministic contradiction adjudicator and Graphiti/Zep's LLM-judged contradiction invalidation, WITHOUT importing Graphiti's cloud-LLM judge. ELAI's `audit_conflicts` (`crates/memory/src/contradiction.rs:64`) only flags a contradiction when two currently-valid rows share a BYTE-IDENTICAL `(project_id, scope, key)` and their `value` JSON differs (lines 75-80, 97-102); it CANNOT detect two facts that are semantically opposed across NON-matching keys. This F-N adds a SECOND pass that runs ONLY on the `Surface{conflict_kind:"contradiction"}` outcome (and its near-miss key neighbours), pre-filters candidate pairs by the existing key/entity grouping so the model sees ~2 rows, and feeds each pair to a LOCAL, deterministic-argmax NLI cross-encoder on ELAI's already-owned `ort`/ONNX substrate (the same runtime the reranker uses). ## Context

ELAI ships a DETERMINISTIC, non-LLM contradiction path on a non-destructive bi-temporal substrate. `audit_conflicts` (`contradiction.rs:64-143`) lists currently-valid rows for a `(user_id, fact_type)`, groups them by `(project_id, scope.as_str(), key)` (line 75-80), and for each group of >=2 rows flags `conflict_kind="contradiction"` only when `older.value != newer.value` for the SAME byte-identical key (line 97-102). Resolution is trust-tier priority (T0=3 .. T3=0, line 152-160), but tier-supersede fires ONLY when `auto_supersede_by_tier==true` AND the newer tier is strictly greater (line 104-112); otherwise it returns `ConflictAction::Surface{older_fact_id, newer_fact_id, conflict_kind}` (line 114) — surface-to-user, both rows survive. The module header (line 18-23) explicitly DEFERS LLM-backed semantic detection to "E-5-followup." The `mem0_dispatcher` write path (`mem0_dispatcher.rs:144-212`) is the same shape: `find_matching_current` is an exact-key linear scan (line 230-256, key compare at 244) + a byte-identical `row.value == candidate.value` compare (line 189), superseding on key-match + value-diff + non-decreasing-confidence (line 196-205).

The non-lossy substrate ALREADY exists. `supersede` (`store.rs:208-265`) closes the old row (`valid_to_ms = now_ms`, `superseded_by = new_fact.fact_id`) and INSERTs the replacement in ONE transaction; its docstring cites "Zep §2.2.3" (line 207). `soft_close` (`store.rs:303`) closes a single row without a replacement. So ELAI already MIRRORS Graphiti's transaction-axis non-lossiness — only the TRIGGER differs, not the storage. F-5 quarantine (`quarantine_broadcast.rs`) is purely age-based (`staleness_ratio = age_days / half_life_days`, threshold 1.5, line 53/101-102) and its docstring (line 111-114) states it does NOT run the contradiction adjudicator — orthogonal, composes.

The gap (verdict): ELAI cannot detect a contradiction between two facts that are semantically opposed but do NOT share a byte-identical key string + identical JSON shape. Its adjudicator is a string-equality grouper with a tier tiebreak (`contradiction.rs:75-80, 97-102`). Graphiti/Zep's `resolve_extracted_edge` / `resolve_edge_contradictions` is a semantic judge that, on contradiction, sets the loser's event-time `invalid_at = the invalidating edge's valid_at` and returns it NON-destructively in `invalidated_edges` (Graphiti `edge_operations.py @ v0.29.1`, lines verified verbatim: `resolve_extracted_edge` L656, `resolve_edge_contradictions` L629, `invalid_at = resolved_edge.valid_at` L667, `invalidated_edges` returned not deleted L897). So ELAI misses paraphrase / implication contradictions across non-matching keys (e.g. fact A key=`prefers_db` value=`postgres`, fact B key=`migrated_off` value=`postgres in favour of sqlite` — semantically a contradiction of A, but A and B never share a key so `audit_conflicts` never pairs them).

The instrument choice (verdict, HIGH confidence): a CLOUD LLM judge is the WRONG instrument. arXiv:2506.09501 (NeurIPS 2025) confirms `temp=0 + fixed seed` does NOT yield deterministic cloud output — continuous batching + GPU/TP-variant kernel reduction order breaks FP associativity; an auto-close decision could flip between identical ELAI_SEED replays, directly contradicting ELAI's deterministic-trust-spine value prop. A LOCAL deterministic-argmax NLI cross-encoder delivers the same recall at zero cloud spend, on the `ort`/ONNX runtime ELAI already runs. CAVEAT (do NOT regress): "deterministic" for the local cross-encoder is DIRECTIONALLY true (argmax over a wide 3-class logit gap) but NOT provably bit-identical — the same GPU FP batch-variance class (arXiv:2506.09501) applies to the NLI logits too. The verdict states the honest framing: "practically deterministic / robustly stable for replay," NOT "fully seed-invariant."

DEFERRED (explicit, do NOT scope-creep): (1) the DKG cascade exact-text join (`crates/knowledge/src/dkg/mod.rs` concept==fact_id exact-equality) is a SEPARATE limitation needing embedding/alias resolution — NOT this F-N. (2) F-5 age-based quarantine STAYS as-is (Graphiti has no time-decay; that remains ELAI's edge over Graphiti, not a gap to close). (3) the cloud-LLM judge (Option A) is REJECTED on determinism grounds, not deferred.
