## Context
Why this matters: the named, externally-demanded market gap (report 8/16/18) is vendor-neutral, cryptographic, REPLAYABLE evidence rendered where supervision happens. ELAI already ships the replayable form (G-2 RRA: action-stream + seed + verdict-hashes + blake3 root, `replay --verify`). But replay-and-trust verifies that the RECORDED stream is internally consistent; it cannot prove the run was EXTERNALLY faithful (that the agent really saw those API responses, those file contents, those web pages) and it faithfully reproduces an incomplete record if recording dropped an effect (the E1 gap K-21 closes). The strict-stronger property — RE-EXECUTABLE — is the wedge: a third party takes the cassette of the taint-ingested external bytes + the pinned environment and RE-RUNS, getting the same verdict from the recorded external world rather than trusting the recording. Nobody publishes that (the empty cell). The fill is mostly composition (J-14's content-keyed `rra export-fixture` cassette + G-1's captured ingest bytes + a pinned OCI/Nix/CAS env), so the capability is a J-14 EXTENSION; the K-native job is to PROVE+PACKAGE it: bank the differentiator now as a [DESIGN] claim (the cassette format + tiered fidelity are designed, parts are WIRED) with the measured re-execution-fidelity number [BENCH-PENDING] on the J track — exactly the K-15/K-17 [BENCH-PENDING] discipline.
