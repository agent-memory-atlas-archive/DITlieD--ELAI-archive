## Context
Why this matters: the user's "it only improves as it gets used" is right in shape but lethal in one assumption — that "useful" can be measured by the system that benefits from saying yes. The run's §4 states it plainly: a self-improving archive whose usefulness signal is author-able by the producing model collapses (three independent groundings: Misevolve, F-10's measured +37.6% security degradation, ELAI's own self-flagged GAP-1/GAP-2). The determinism doctrine's answer is already designed (VD-1..VD-5: execution-grounded never bytes/self-confidence; behavioral trap with measured recall; worst-case/lineage promotion; stronger-than-generator + cross-family) and partly built (Track-7 H-43..H-48). What is MISSING is the binding pre-gate: no conditional-routing rule forces a future VCG/case-reuse/playbook/DGM executor to obey it, so the natural shortest-path failure is exactly what the user described — score a case node by "it was retrieved/used" or by an LLM-judged "this helped". K-19 forecloses that, at the case-reuse grain, BEFORE the VCG capability is built. Mechanism: one .claude/rules/ doctrine file (conditional-routing loads it on self-improvement tasks) + a K-1 lint recogniser so positioning copy cannot ship a "self-improving / learns from your code" over-claim without the execution-grounded-fitness correction.

THE FOUR-CLAUSE SELF-IMPROVEMENT-FITNESS INVARIANT (the rule K-19 ships; binds future VCG / case-reuse / playbook-curation / archive-promotion / DGM work):
  SF-1 EXECUTION-GROUNDED-FITNESS-ONLY: a reuse / usefulness / promotion / fitness signal is NEVER a byte-hash (VD-1; the LIVE DGM GAP-1 derived_alpha=blake3(config_bytes) is the exact anti-pattern this replaces — H-43 supersedes it) and NEVER an LLM-judged "this helped / this is better" (VD-2/TD-3, the load-bearing gate is never the LLM). It IS the OFF-AGENT EXECUTION-GROUNDED outcome: did reusing/promoting the artifact cause a gate-PROVEN pass on a HELD-OUT recurrence (D-6 held-out store, H-47 eval firewall, H-43 pass-rate over frozen tests). "It was retrieved" / "it was used" / "the count went up" is NOT fitness; "the gate passed on a held-out instance AFTER it was surfaced" is.
  SF-2 STRONGER-THAN-GENERATOR + ABSTENTION-AWARE: promotion / reuse-fitness is checked by a DIFFERENT pretraining family than the generator (D-13/VD-4 stronger-than-generator) and CREDITS abstention (RD-1: a case that correctly says "I do not apply here" is NOT a failure; penalize confident-wrong at t/(1-t), the abstain bit READ from D-16/H-39 never re-derived). Trap detection is BEHAVIORAL with MEASURED recall on a frozen contrastive corpus (VD-2/H-44), NEVER keyword-grep (the LIVE DGM GAP-2 anti-pattern this replaces).
  SF-3 OBSERVE-FIRST + NEVER-INTO-THE-AUDITOR: any reuse-into-GENERATION (a case / playbook / insight injected as a demonstration) is OBSERVE-ONLY first (GD-4 — measure the recurrence-hit-rate / would-be-usefulness before it can influence generation; the run's §6 Slice-1 -> Slice-2 split), ships DEFAULT-OFF with a wire-dark-allowlist row + a promotion plan (W-2/R9, no default-OFF graveyard), and is NEVER injected into the auditor / critic / adversary context (the H-31 AUDITOR-OBJECTIVITY FIREWALL, arXiv:2510.09905 — generator-side help ONLY; if the independent check reads the same "this usually works" memory it stops being independent and the evidence spine that makes minting trustworthy quietly dies).
  SF-4 STALENESS + SUPERSESSION + REPLAY-SAFE: a case / memory is re-derived against the CURRENT commit + AST identity BEFORE reuse (J-21 commit-aware/state-level validation, "citation-valid != semantically-valid"; H-32 28d TTL on code-grounded facts; G-10 model-drift invalidation). A superseded case is HARD-FILTERED at retrieval (H-31 — the measured Graphiti +68%-token [OUTDATED]-narration trap), never narrated, NEVER DELETED (RV replay integrity). Poisoning: write-time injection scan + retrieval-time authorization + write-quarantine (J-21 / E-5 MINJA / MPBench arXiv:2606.04329 — write-time scanning alone misses benign-at-write poison); per-namespace isolation (J-59) so a poisoned case in one seat cannot leak into another.
conditional-routing loads it on any self-improvement / case-graph / archive-promotion / playbook-curation / memory-reuse / DGM / fitness-scoring task.
