- Today a single reasoning step runs straight-line until it hits the context wall (local) or the GRC budget, then truncates or fails: the model never decides WHEN to compress-and-continue and the harness never resets-and-re-reasons. The cog invariant for REASONING: the model generates the reasoning segment AND proposes a compact progress-distillate; a DETERMINISTIC trigger (context-fill / GRC budget threshold) decides WHEN to checkpoint; a FROZEN admission check decides whether the distillate is acceptable (bounded size + non-empty + uncertainty-preserved); then the harness RESETS the working context and re-seeds the topic with {pinned original goal + admitted distillate} for a fresh pass. This is InftyThink's sawtooth (bounded context, unbounded depth) brought down to WITHIN one GRC/planning/research reasoning step. It is the reasoning-axis sibling of J-39 (decomposition nodes) and J-40 (research steps): the same bounded-context-unit + distill-and-reset discipline applied to REASONING. bound-and-reset, never let-the-model-decide-when. GROUNDED ABSENT 2026-06-16: ELAI does reason-on-distillate at the AGENT/ORCHESTRATION grain (context-compiler->executor->auditor, BSP supersteps, E-25/H-50/H-51 session compaction) and refines by APPENDING (B-39 chat_reflect:409-465), but no within-step distill->reset->re-reason-fresh operator exists; GRC reset_topic (engine.rs:556) clears budget/step counters only, with no distillate carry-forward.

## Steal/build
1. EXP-3 (OBSERVE-ONLY, step 1, no gating until passed): on a local-model reasoning benchmark (MATH500 / AIME24 / GPQA_diamond per InftyThink, plus a coding-reasoning slice) with the 3B/7B, compare straight-line reasoning vs distill-reset at EQUAL total token budget. Win = distill-reset >= straight-line accuracy at LOWER peak context (the sawtooth memory win) AND no abstention/uncertainty degradation (the 2603.24472 guard). Accuracy <= straight-line OR degraded abstention = stays observe-only / context-economy-only. No default-ON until FP/over-reset and abstention-quality bounded on >=3 runs (GD).
2. checkpoint_and_reset operator: extend GRC reset_topic (engine.rs:556, today clears budget + step list only) into checkpoint_and_reset(topic): capture the model-proposed distillate, run the frozen admission check (step 4), clear the topic budget/steps, re-seed the topic with {pinned original goal/query + admitted distillate}. Deterministic when-to-fire (step 3); no model call decides the reset.
3. deterministic trigger: fire the checkpoint when topic working-context fill crosses a fraction of the lane ceiling (ELAI_LOCAL_MAX_CONTEXT * trim_fraction for local, the context-policy seam context_policy.rs:70 / H-50) OR the GRC topic budget (max_chars / max_calls) nears exhaustion. Reuses H-42 ReasoningBudgetScaled / serial-depth budget for the per-pass budget. NEVER the model saying "I'll summarize now."
4. frozen distillate admission (the cog gate, mandatory): the model proposes the distillate as FREE-FORM text -- HD-3 BANS constrained-decode / force-JSON of a reasoning-role output, so the harness parses best-effort (the chat_reflect verdict-parser idiom), never constrains the decode. The harness ADMITS the distillate iff: bounded to the sawtooth floor size cap; non-empty; AND uncertainty-preserved (open questions / flagged hedges / abstention markers present in the pre-reset trace survive into the distillate -- the 2603.24472 guard, cross-checked against D-16 RefusalDecision / AbstentionScored). A distillate that strips all uncertainty FAILS admission -> re-distill once, else escalate (I-7) / fall back to straight-line truncation. Pin the ORIGINAL goal in every re-seed (not only the rolling distillate) to resist iterative-summarization directional-attractor drift (2601.08846).
5. host loop: the B-39 chat_reflect AUDITOR refine loop (chat_reflect.rs:409-465) today APPENDS the prior verdict (accumulate, converges on next_best==prev_best). J-42 adds the distill-reset MODE as the deep/local path: checkpoint_and_reset between passes instead of append. Also wire the operator into the GRC reasoning-step path (PipelineGrc hot paths) and the planning/research step loops so a single long reasoning step gets the sawtooth.
EXCLUDED: SFT on InftyThink-reconstructed datasets (the paper's 333K-instance reconstruction; RUNPOD-PENDING -- the inference-time prompted operator ships first and may underperform the fine-tuned version, honest residue); population-aggregation (RSA 2509.26626 is the N-best PARALLEL sibling already partly present as B-39 N=4, NOT single-chain reset); constrained-decode of the reasoning or the distillate (HD-3 banned); any model-decided reset trigger.

## Integration
Extends, does not replace, GRC `reset_topic`: that stays the budget-clearer; `checkpoint_and_reset` is the superset that also carries the admitted distillate. The deterministic trigger reuses the H-50 context-policy fraction + the H-42 serial-depth budget. The B-39 refine loop gains a distill-reset mode alongside its existing append mode; the operator also wires into the PipelineGrc reasoning-step hot paths and the planning/research step loops. Honest residue (SWEnergy, ICSE-2026, same as the DD wave): distill-reset makes a small local model FIT more reasoning depth into bounded context, it does NOT make it CAPABLE beyond its reach (4B ~0% agentic resolution) -- hard reasoning still escalates via I-7; necessary, not sufficient, for local viability. Second residue (2603.24472): self-distillation can suppress epistemic uncertainty and degrade OOD reasoning up to 40% -- the uncertainty-preservation admission check is the static mitigation, EXP-3's abstention-quality measurement is the load-bearing guard; do NOT ship default-ON if abstention degrades. Third residue: InftyThink's gains came WITH SFT; the prompted-only operator may be weaker.

## Open questions / risks
- EXP-3 gates default-ON: prompted-only (no SFT) distill-reset may not reproduce InftyThink's fine-tuned gains; if accuracy <= straight-line at equal budget, J-42 stays an observe-only / context-economy-only operator (still useful: lets a long reasoning step FIT under the local ceiling instead of truncating).
- the uncertainty-preservation check is heuristic (does the distillate retain hedges / open questions?); a model can emit a confident-but-lossy distillate that passes a shallow check. The real guard is EXP-3's abstention-quality measurement, not the static check (2603.24472).
- directional-attractor drift (2601.08846): even with the pinned goal, repeated distillation can converge to a generic restatement; cap the reset-pass count (a depth cap, like J-39's MAX_SPLIT_DEPTH) and require measurable per-pass progress or escalate.
- CLOUD vs LOCAL split: cloud keeps the cache prefix (H-1 / H-50 cloud policy), so a reset that discards the prefix would BURN the cache. J-42's reset is a LOCAL-lane-first operator; on cloud it must respect keep-cache-prefix (likely append-mode on cloud, reset-mode only local). Decide the split at edit -- mirrors H-50's opposite-policies finding.
