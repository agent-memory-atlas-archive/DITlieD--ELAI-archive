Same-family dispatch is REFUSED (the DD-3 floor catches the inverse in code; this enforces it at the review grain).
4. ESCALATION ROUTING (the teeth): a flagged advisory finding routes to the orchestrator/user as an explicit DECISION (the handoff-protocol BLOCKED=handoff-entry shape, or an orchestrate/auto-orchestrate handoff-mediation entry), with explicit weighting/visibility — NOT a dashboard tile that decays unread. 5. DEGRADATION HONESTY: gpt-bridge / a second family is rate-limit-fragile and occasional (browser-subscription, POOL_EXHAUSTED possible). When the second family is unreachable the review degrades to SINGLE-family — which weakens D5 — so it RECORDS a DOCTRINE-DEBT row on the review itself (current_disposer = "single-family-degraded"), never silently passing single-family advice off as cross-family (the DP design V3 residue made first-class).
EXCLUDED: an LLM-as-judge on a release-gating path (D5, the whole point — the advisory NEVER gates); same-family self-critique counted as verification (banned, DD-3); a dashboard-only surface with no escalation (C3: ignored-by-construction); treating uncalibrated advice as the satisfied D5 check (the pre-calibration label forbids it); deep-research as the advisory (gpt-bridge has no deep-research on grok — effort=expert/heavy instead; and the advisory is a one-shot diversity vote, not a research run).

## Open questions / risks
- Corpus labelling cost + provenance: 100-300 human-labeled doctrine-conformance traces is real human effort; who labels, and how is label quality controlled (a mis-labeled corpus makes kappa meaningless)? Lean: the user labels the held-out slice; the rest seeded from DP-4 real findings + one synthetic per DD-* class.
- Cross-family availability: if gpt-bridge is down for a stretch, the D5 check is unavailable — does the pipeline BLOCK (over-strict, stalls) or proceed-with-recorded-debt (lean: proceed + debt row, since the advisory is non-load-bearing by design)? Decide at edit; default proceed+debt.
- kappa drift: a model-family update can move the advisory's agreement; the kappa is not a one-time measurement (re-measure on a cadence, or treat a stale kappa as debt).
- Decoration risk persists even calibrated: a calibrated advisory whose escalations are routinely overridden is still ignored — track escalation ACCEPTANCE/override rate as a second health signal (DP-4).
