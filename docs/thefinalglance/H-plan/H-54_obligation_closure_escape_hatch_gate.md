- Premise: ELAI's Track-7 H-44 already NAMES its own weakness — `score_candidate_for_traps` (trap_tasks.rs:123) is a substring keyword grep over arrays the code self-flags "unsound" (GAP-2, P0): a keyword-FREE verifier-gaming candidate passes untouched. AlphaProof Nexus (DeepMind, arXiv:2605.22763, the proof corpus cloned to docs/.source/alphaproof-nexus-results @ 0647711) documents EXACTLY this evasion in a formal-proof setting and ships the deterministic production fix: (1) a generator RELOCATES the unproven `sorry` into a renamed helper lemma that just re-states the target (the top theorem now looks sorry-free); (2) it introduces a FALSE "known-result" lemma that is actually hallucinated and never proved. AlphaProof's defense is NOT keyword grep and NOT an LLM judge — it INSPECTS THE WHOLE DEPENDENCY CLOSURE of the proof, and an escape hatch (`sorry`/`admit`/axiom/`assume`) ANYWHERE in the closure disqualifies. H-54 ports that mechanism: a deterministic obligation-closure escape-hatch scan as the cheapest FIRST leg of trap detection on ELAI's formal-verification lane (E-53) and as the deterministic core H-44's keyword grep was a stand-in for. It is the wiring R7 insight applied to proofs: a closure that bottoms out in an admitted/assumed obligation does NOT satisfy "proved", exactly as a symbol whose only caller is test code does not satisfy "production-reachable".
