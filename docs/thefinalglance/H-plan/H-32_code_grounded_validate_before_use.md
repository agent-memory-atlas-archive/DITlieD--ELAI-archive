# H-32 -- Tier A code-grounded fact memory (validate-citation-before-use)
- Track 4 (UX + USER-MEMORY) | lever TRUST | grounding STRONG | nature BUILD (on DKG) | effort M | WAVE 4 | depends H-31
- Premise: when ELAI tells the user "this repo bans `.unwrap()` in prod" or "swiftide was rejected", that durable claim must still be TRUE about the code as it exists right now, not as it existed when the fact was written. A code-grounded fact that cites a symbol which was since renamed/deleted must NOT be silently injected and acted on; it must re-validate against current code first and, on failure, surface a confirmation + emit an off-agent SSB row instead of quietly steering the model on a stale premise. This is the core trust product (ELAI cant lie) applied to its own memory.

## Steal/build
BUILD on the existing crates/knowledge DKG + crates/memory bi-temporal store. The validate-before-use mechanism is a Rust REIMPLEMENTATION of two odysseus MIT prior-art guards, NOT a port:
- odysseus src/teacher_escalation.py:133 `_UNTRUSTED_TRACE_GUARD` (const, injected at :388 escalate_and_learn and :617 run_teacher_inline) — the validate-before-PERSIST boundary: an untrusted trace is wrapped before a trusted model consumes it so an injection cannot become a learned artifact. ELAI analog inverts the timing to validate-before-USE: a code-grounded fact's CITATION is re-checked against current code before the fact is allowed to influence the prompt.
- odysseus src/teacher_escalation.py:621-626 the NO_SKILL distill gate (`if skill_response and "NO_SKILL" in skill_response and not _extract_skill_json(...)` -> decline, reason "problem not reproducible") — persist a learned artifact ONLY when it is validated/reproducible. ELAI analog: inject a code-grounded fact ONLY when its citation re-resolves; a non-resolving citation is the "not reproducible" decline path.
- odysseus services/memory/skill_extractor.py:66 `maybe_extract_skill` (complexity-floor gate) + :57 `_has_duplicate_title` — prior art for the WRITE-PATH CLASSIFIER (only promote to a durable code-grounded fact when it clears a floor; dedup before persist). REIMPLEMENT in Rust against SSB rows; use blake3 for any fingerprint (Anti-Stale rule), never odysseus's hashlib choice.
GitHub Copilot agentic memory (github.blog 2026) is the production proof the two-axis design works: code-grounded facts each carry a citation, are re-validated before use, expire on an unused TTL, and "only validated facts are used".

## REVISED scope (W-10 tiered)
Tier-1 (ships now, in-process, no network): (1) extend `MemoryFact` with a VALIDITY axis distinct from recency — a `last_validated_at_ms: Option<u128>` + the citation stored in `evidence_pointers` as a structured `dkg:<symbol_name>@<file>:<line>` pointer (parse helper, blake3 of the canonical SymbolRef as the stable citation key). (2) a `revalidate_citation(fact, dkg_name_index) -> Validity` function: resolves the cited symbol via `ensure_name_index` + `find_symbol_at`; Valid if the symbol still exists at a resolvable site, Stale if it resolved before but no longer (renamed/deleted), Unknown if the index is unavailable (treated as FAIL per R2, not "skip"). (3) the WRITE-PATH CLASSIFIER `classify_fact_tier(candidate) -> Tier` (A = code-citable DomainKnowledge/Mistake with a resolvable citation at write time; B = preference -> H-31). (4) the read-side gate: extend `get_relevant_facts` so a Tier-A fact is injected ONLY if `revalidate_citation == Valid`; Stale -> excluded + emit `fact_validation_failed` SSB row + the caller surfaces a confirmation instead of acting. (5) unused-TTL expiry with reset-on-validated-use: a Tier-A fact unread for the TTL window (default 28d per the Copilot MEASURED figure) is soft-closed; a validated USE resets the TTL (bumps `last_observed_at_ms`, retrieval.rs:109-116 already bumps on read — extend to also stamp `last_validated_at_ms`).
DEFERRED (W-10): the ONNX/embedding semantic-similarity leg for citation fuzzy-match (nli-onnx feature, model not on disk per semantic_contradiction.rs:23-24) — Tier-1 uses exact DKG name/line resolution only. Cross-project promotion of a code-grounded fact (Scope::Global, fact.rs:101) stays GATED-deferred (no promotion code exists, fact.rs:95-98).
Local-token discipline: validation runs only over the SMALL candidate slice retrieval already selected (RetrievalFilter top-K), never the whole store; injected Tier-A slice stays inside H-31's ~100-500 token cap. STALENESS handled at READ time via the validity gate (excluded, NOT narrated as [OUTDATED] — the Graphiti +68%-token trap); bi-temporal supersession at WRITE time (soft_close older, never DELETE — DELETE breaks SSB replay). Contradiction-detection on WRITES uses the CLOUD model only (spare the 7B). Decay (HALO half-life, decay.rs) is the BACKSTOP; the citation-validity gate is the primary mechanism.
AUDITOR-OBJECTIVITY FIREWALL: auditor/critic/adversary roles receive ZERO Tier-A injection (Personalization-Trap arXiv:2510.09905) — the gate checks role before injecting. HARD-EXCLUDE secrets/keys/PII/file-contents from any captured fact value (a citation is a symbol POINTER, never embedded source).
