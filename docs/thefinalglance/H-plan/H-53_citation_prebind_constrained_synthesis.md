# H-53 — citation pre-binding + constrained synthesis on the answer path (ghost citations made structurally impossible; stolen from Perplexity's answer-stage design)
- Track 11 (EXTERNAL-SYSTEM RESEARCH STEALS) | lever VERIFIED-BEFORE-SEEN / cant-lie | grounding STRONG (on ELAI's own D-11/E-48; the Perplexity-specific mechanism is MEDIUM, see Grounding) | nature BUILD | effort M-L | WAVE 11 | depends E-48 (the CitationVerifier consumer + the web-research answer path), E-35/C-26 (the constrained-decoding substrate); composes H-52 (the same deterministic verbatim-snippet->anchor resolver), D-16 (Mode-E refusal), 3E (the context-budget slot)
- Premise: ELAI's MOST-MARKETED property — grounded, cant-lie answers — is enforced TODAY as DETECT-AFTER, not PREVENT-BEFORE. The oracle/researcher answer path (C-30 oracle_cache + repl_command /research|/ask + the researcher agent's ORACLE OUTPUT FORMAT) has the MODEL EMIT freeform `[N]` citations; E-48's 4-stage CitationVerifier then does GhostCite hardening AFTER generation, and Phase 2B grounding verifies CLAIMS after the fact. That is correct but structurally weak: a ghost or mis-attributed `[N]` is something the system CATCHES (then must repair or refuse), not something the architecture makes IMPOSSIBLE — the model is free to write `[3]` next to a sentence the retrieved evidence does not support, and the system's job degrades to detection (exactly the failure that makes naive grounded-answer systems leak). Perplexity's documented answer stage does the opposite: it embeds numbered, ranked evidence anchors INTO the prompt BEFORE generation, then constrains synthesis to cite-as-you-generate from that fixed set ("citations are predetermined, not retrofitted"). H-53 ports that SHAPE: make citation assignment a first-class PRE-GENERATION stage so a hallucinated/ghost citation is STRUCTURALLY impossible on the answer path, the off-agent-artifact doctrine pushed down into the answer SCHEMA — the model is structurally unable to assert a citation id that was not pre-bound, so it cannot fabricate one.

## Steal/build

- THE CONSTRAINT (reuse, do NOT re-author): decode the answer under a grammar that permits inline `[N]`/`[N,M]` markers ONLY from the pre-bound id set, plus an explicit unsupported-span token. REUSE the E-35 XGrammar substrate + C-26 `decoding.rs` PER_ROLE_DECODING (the researcher/answer role gets the citation grammar) — do NOT build a second constrained-decoder (GD-1). HD-3 GUARD: constrained decoding degrades REASONING (arXiv:2408.02442) — the grammar constrains ONLY the citation-marker token positions (a pure-data emission, the HD-3 carve-out), NEVER the prose/reasoning tokens; a grammar that force-shapes the whole answer is a FAIL.
- THE ANCHOR RESOLVER (reuse H-52, the convergence): mapping a synthesis claim back to the exact evidence excerpt is the SAME deterministic verbatim-snippet->anchor problem H-52 solves for review findings (Perplexity independently uses a deterministic resolver for citations — noted convergence). REUSE H-52's `anchor_finding`/normalize+match primitive for excerpt binding where a span must resolve to a specific anchor; do NOT re-author it (GD-1, W-7 confirm symbol at authoring).
- THE VERIFY LEG BECOMES CHEAP+STRONGER (compose E-48): E-48's CitationVerifier degenerates from an open-world "does this freeform `[3]` exist and support the claim" ghost-hunt to a CLOSED-set membership+support check — "does pre-bound anchor 3's blake3-pinned excerpt still support this span". REUSE E-48's `citation_verified` row (extend its payload with `anchor_id` + `pre_bound: true`); do NOT re-implement the verifier (GD-1).
- THE HONEST REFUSAL (compose D-16/D-17): a synthesis step that cannot ground a load-bearing claim in ANY pre-bound anchor routes to Mode-E refusal (the shipped conformal RefusalDecision, D-16; refusal-rate SLA, D-17), NEVER to an invented citation. Read the abstain bit from D-16, never re-derive (GD-1).
