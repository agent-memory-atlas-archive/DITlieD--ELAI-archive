## Why N-plan exists (read this before anything else)

The LACUNA program (through M) drove ELAI's spec to capability-saturation. The interlace pass found the residual
weakness is NOT missing features — it is that the features were authored against SUMMARIES, one letter at a time,
so good capabilities that would be dramatically stronger CONNECTED instead sit as parallel machines that do not
talk to each other. The talking that DOES happen (GD-1 compose-not-restate, C/E closure tables, the K/J split,
Section-4 rejected ledgers, H/I/J per-symbol grounding maps) runs through ONE hand-maintained artifact
(ELAI-FEATURE-MAP.md) plus prose edges, with ZERO machine checking. The corpus contains a proven live instance
of the failure (J-SUMMARY_INDEX.md:2 self-declares it drifted from its own letter). The user's fear is right
about the MECHANISM (summary-mediated authoring fragments) and wrong about the SCALE (duplication mostly stopped
by the J era). N-plan's single job: mechanize what the culture already does by hand.

THE CENTRAL FINDING (from the source pass, AS-SPECIFIED): wherever a later plan EXTENDED a base REGISTRY
(VerificationMethod enum 2B, RRF ranker list 1E, context slots 3E, rules predicates 3F, SSB action_types 3B,
RuntimeBackend enum 4M, AgentRole 3C), cross-plan composition happened AUTOMATICALLY and never fragmented
(17->576 action_types under the golden lock, zero drift). Wherever a later plan MINTED PARALLEL machinery for
an EXISTING concern (four claim types, ten routers, four failure taxonomies, five provenance scales, six
verification-intensity deciders, four counterfactual engines, five context cores), the fragmentation appeared.
So the interlace program is ALSO an ACTIVATION program, not an invention one: N-N units UNIFY existing units
into one registry each, and the meta-rule M-1 (one-registry-per-concern, enforced at plan-authoring time,
built as N-2) prevents the next letter from re-fragmenting. N ships under the SAME hard executed wiring
done-gate F/G use, so no unification can ship half-done (two live cores = the split-brain it exists to kill).
