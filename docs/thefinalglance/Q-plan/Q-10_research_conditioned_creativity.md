- Premise: ELAI already has grounded recursive research, verified citations, contradiction-bearing reports, Cosmos artifacts, one-call conjecture generation, unfused novelty/grounding/value axes, and deterministic execution receipts. What it does not yet have is a proved interface that turns research into **new target mechanisms** without allowing source citations to masquerade as target evidence. Q-10 adds one materially new intervention: verified source research is compressed into a typed relational analogy packet, used in one generation call, then discarded as authority; target grounding and execution stay separate. This is not the refuted FDL: there are no cycles, ProbeUtility, operator allocation/fade, shared archive memory, or planning-to-runtime archive bridge.

## Steal/build

Build a versioned `ResearchInspirationPacket` carrying a source problem/mechanism, object mappings, shared relations, invariants, disanalogies, transfer hypothesis, predicted observation, target falsifier, contradiction refs, verified source refs, and per-mechanism/relation-source-predicate support edges. Its binding label is `evidence_scope=SOURCE_ONLY`: the source citations prove only the source mechanism and source-side relation predicate, never the target side or sharedness claim. Every conditioned candidate emits a `TRANSFER-EDGE` and must independently earn target anchors, a target falsifier, grounding receipts, and execution value.

Before any consumer changes, run a locked five-arm ladder: `DIRECT`, source-blind `MATCHED_SCAFFOLD`, `VERIFIED_EVIDENCE`, `RELATIONAL_PACKET`, and schema-valid relation-`SHUFFLED_PACKET`. B-CREATIVITY-0 uses K=30 exactly enumerable executable strategy tasks; B-CREATIVITY-1 uses K=30 real ELAI improvement fixtures with hidden deterministic micro-executors; B-CREATIVITY-2 is an observe-only L-10/L-23/L-24 explore ablation. The matched scaffold controls for extra target deliberation; the shuffle controls for relational specificity. A B0 pass permits only B1. A B1 pass permits planning-skill adoption. Only a B2 pass under PS-3, N-16, cost, and lane-wall guards permits a production explore consumer.

EXCLUDED: raw full-paper/report/archive prose as the default treatment; source citations presented as target evidence; an LLM judge as a primary promotion gate; fusion of novelty, grounding, value, validity, and cost; feedback cycles; ProbeUtility/`PROBE`/`--discriminate`; archive-conditioned operator rotation/fade; B-2/B-4 resurrection; a planning-archive-to-L bridge; packet retrieval in code-fix, auditor, critic, or verified-case paths; runtime work after a synthetic-only win.
