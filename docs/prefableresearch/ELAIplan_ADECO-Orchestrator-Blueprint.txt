### 1. Defeating the Cache-Eviction Trap & Multi-Model Mess

If you swap models or mutate prompts, you cannot share a cache. We must decouple the "Static Knowledge" from the "Volatile State."

* **Bipartite Prefix Invariance (I-10):** Strictly split every prompt into two zones.
* *Zone A (The Frozen Prefix):* System Instructions, JSON XGrammar rules, the DKG RepoMap, and the **complete** 50+ tool catalog. This block receives an explicit `<cache_control>` tag and is *never* mutated. To change what a specific model/agent can do, mutate the `tool_choice` parameter in the API payload, not the prompt text.
* *Zone B (The Volatile Tail):* The current task and compressed tracebacks.


* **The Cache "Micro-Heartbeat":** To survive local validation loops that exceed Anthropic's 5-minute TTL, the ELAI Rust orchestrator must track execution time. At the 4.5-minute mark, ELAI fires an asynchronous `<ping>` (1 token generated) to the cloud API using the *exact Frozen Prefix*. You pay fractions of a cent (due to the 90% read discount), but it instantly resets the 5-minute TTL, keeping the massive 100K-token context permanently hot in the provider's GPU.
* **Cross-Model Handoffs via PABU Belief States (I-11):** When escalating from a Local 7B model to Cloud Sonnet, **never** send the local model's raw conversational history. Instead, the orchestrator condenses the local history into a dense, 1,500-token `BeliefState` JSON (e.g., `{"tried": ["Approach A"], "failed_because": "Borrow checker error on line 42", "current_ast_state": "..."}`). The Cloud model receives the Frozen Prefix (Cache Hit) + the tiny `BeliefState`. The context stays pristine, preventing quality degradation.

### 2. Curing Context Bloat (The Vividness Trap)

Cloud models degrade in reasoning quality when bloated with long contexts. We must compress data *before* it hits the network.

* **AST-Aware LLMLingua-2 Edge Compression (I-14):** Never send raw compiler tracebacks over the network. Pass errors through a local `LLMLingua-2` bidirectional encoder. Because it uses token-level classification rather than autoregressive generation, it compresses text **3x to 6x faster** than traditional methods. By combining it with a `tree-sitter` mask, you preserve strict AST structural syntax while aggressively crushing conversational fluff. A 10K-token compiler panic becomes a 500-token dense semantic signal.
* **N-Gram Abbreviation (CompactPrompt):** For repetitive DKG schemas (e.g., `AbstractFactorySingletonImpl::initialize`), the orchestrator builds a local, reversible dictionary mapping these to short symbols (e.g., `~A1`). The cloud model reasons over the compressed symbols, instantly reducing code-heavy prompt tokens by 30-50%.

MCTS (Monte Carlo Thought Search) branching creates massive, parallel API calls that trigger "Thundering Herd" API blocks.
