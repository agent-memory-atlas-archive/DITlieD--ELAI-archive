  2. Types: "portfolio site with dark theme, project grid, contact form"
  3. ELAI researches via SearXNG: picks framework, verifies packages on npm,
     checks latest versions, finds best practices
  4. Designer decomposes: 3-4 concepts, ~8 phases, ~18 baby steps
  5. Activity stream shows: scaffold template applied -> tests written ->
     code generated -> validated -> audited -> next step
  6. User sees diffs, accepts/declines, adds steering constraints
  7. Dev server starts, preview link appears, user clicks to see website
  8. Task completes, code committed

WHAT MAKES IT "HIGH QUALITY WEBSITES":

  - Scaffold templates: curated, tested project starters (no hallucinated configs)

    no inline styles, no !important, all enforced deterministically at Tier 1/2
  - Dev server validation: build passes + server responds + no console errors
  - TDD: tests written before every baby step, auditor verifies independently
  - Baby step sizing: 40 LOC max per step (7B model), small enough to get right

    3. Health check pattern: factory-static checks output structure
       (/{locale}/index.html, /theme.css, /assets.json). ELAI checks:

========================================================================
BLOCK 4: DASHBOARD (4K.1 through 4K.5, Tauri MVP)
========================================================================

Full step definitions are in docs/specs/guide/steps/phase-4K.txt.
Each step has PRE_GATE, TASK, DETERMINISTIC_CHECK, ADVERSARIAL,
and ACCEPTANCE sections. Visual identity from
docs/specs/guide/dashboard-design.txt (colors, typography, layout language)
applies to Tauri webview identically.

Tech decision: Tauri v2 replaces Axum + SolidJS.
  - Eliminates: HTTP REST API, WebSocket protocol, CORS, port management
  - Tauri #[tauri::command] calls SsbViewer (Rust) directly from frontend JS
  - Frontend: Svelte in Tauri webview (small, reactive, good Tauri match)
  - Data flow: frontend polls SsbViewer via invoke() every 500ms (no WS needed)
  - Distribution: single .exe (Tauri bundles WebView2 bootstrapper on Windows)
  - Verified: tauri = "2.10" on crates.io (v2.10.3, 2026-04-16)

Summary of what each step delivers:

  4K.1   SSB READ-ONLY VIEWER LIBRARY
         SsbViewer struct. 8 typed query functions. 2 new SSB action types
         (INTERVENTION_REQUEST, INTERVENTION_RESPONSE). Read-only SQLite
         connection. <10ms per query. HEALTH_SNAPSHOT and WINDOW_STATE
         deferred to post-MVP.
         ~250-350 LOC

  4K.2   TAURI APP SCAFFOLD + TAURI COMMANDS
         New dashboard/ crate (Tauri binary). 6 #[tauri::command] functions
         wrapping SsbViewer. Svelte frontend scaffold with visual identity
         (dark theme, teal accents). tauri.conf.json, build.rs.
         No HTTP server. No WebSocket. No CORS.
         ~250 LOC (Rust + Svelte scaffold + config)

  4K.3   PROJECT SELECTOR + TASK INPUT (single screen)
         "+ New Project" (name + parent picker, creates folder) or
         "Open Existing" (folder dialog). Template picker for empty folders.
         Task input with [Start] button.
         4 Tauri commands (list_projects, create_project, select_project, submit_task).
         ~280 LOC (Svelte + Rust commands)

  4K.4   MAIN WORKSPACE: PLAN TREE + ACTIVITY FEED
         Two-panel layout: plan tree (left) + activity feed (right).
         Draggable divider. Status bar with FSM state.
         Plan tree: phases/steps/baby steps with status indicators.
         Activity feed: reasoning, edit, validate, test, preview entries.
         Preview link: clickable localhost URL via shell::open.
         500ms polling via setInterval + invoke().
         ~370 LOC (Svelte, no new Rust commands needed)

  4K.5   DIFF VIEWER + ACCEPT/DECLINE + PREVIEW LINK
         Unified diff viewer for INTERVENTION_REQUEST (ApproveChange).
         Accept/Decline/Retry controls. Per-hunk granular control.
         Multi-file navigation. 1 new Tauri command (get_action_detail).
         Preview link in activity feed opens system browser.
         ~270 LOC (Svelte + 1 Rust command)

  BLOCK 4 TOTAL: ~1390-1490 LOC, 5 sessions
