phase-4D-SURGICAL — Surgical Decomposition for /task
=====================================================

Status: SHIPPED in C-30 (SCHEMA_VERSION 61 -> 62). This file is the spec
record. Cross-reference workflow/reasoning/C-30-decisions.md (DECISION-1
through DECISION-15 plus NOTE-A through NOTE-D) and the implementation in
.elai_cc/crates/orchestrator/src/surgical_decomposer.rs.

Goal: when a /task is invoked with `--surgical`, replace the default
ConceptDecomposition pipeline with a DKG blast-radius-driven surgical
plan that bounds the change to its real impact set, classifies complexity,
and enforces LOC gates appropriate to the active ExecutionMode.

Types (verbatim from C-30 DECISION-5 / NOTE-A)
----------------------------------------------

- SurgicalPlan { steps, complexity_class, affected_set, total_loc_estimate,
                 regression_gates }
- AffectedSet { files: Vec<PathBuf>, symbols: Vec<String> }
- ComplexityClass { Simple, Medium, Complex }    // thresholds below
- RegressionGate { gate_kind, target_symbols, source_tests }
- TestBaseline { passing_tests_count, last_recorded_at }
- SurgicalStep { id, description, target_files, regression_gate_ref }

Complexity thresholds (from C-30 implementation)
------------------------------------------------

Simple:  files ≤ 3 AND loc ≤ 200   → step cap 1
Medium:  (files ≤ 8 OR loc ≤ 500) AND not Simple → step cap 4
Complex: otherwise → step cap 8

Step generation
---------------

SurgicalDecomposer::decompose(task, dkg, mode) -> SurgicalPlan
  1. DKG blast-radius traversal: query_callers + query_dependents +
     query_data_flow at depth ≤ MAX_C30_DEPTH (= 8), cycle-guarded with
     HashSet<i64>. Collects AffectedSet.
  2. ComplexityClass classification per the thresholds above.
  3. RegressionGate injection per step: pulls test-coverage metadata
     from the DKG (test → covered-symbol edges) and synthesises one
     `RegressionGate` per SurgicalStep so the audit phase can re-run
     exactly the right test subset.
  4. Constrained step generation respecting the per-class step cap
     (1 / 4 / 8). Steps exceeding the cap are merged or dropped with
     an explanatory note.

LOC gate
--------

Threshold constants:
  SURGICAL_LOC_WARN_THRESHOLD     = 500
  SURGICAL_LOC_ESCALATE_THRESHOLD = 1000

When `total_loc_estimate > 500`:
  - Emit SSB row `surgical_loc_warning { loc_estimate, threshold }`.
  - INTERACTIVE mode returns `ConfirmationRequired` (caller prompts).
  - AUTONOMOUS mode with `autonomous_confirm_above_loc = 500` blocks
    until confirmation OR `autonomous_refuse_above_loc = 1000` aborts
    outright.

CLI / SSB
