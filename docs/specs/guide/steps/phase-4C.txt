KEY DESIGN DECISIONS (from audits and specs)
  1. T3 is pattern-match only, no LLM (audit-results.txt BLOCK 2).
  2. Hooks intercept IPC messages in orchestrator (orchestrator.txt section 12 Tier C):
     PreToolUse fires when orchestrator receives ToolRequest/BashRequest from agent.
     PostToolUse fires after tool execution, before ToolResult sent back to agent.
     PostToolUse also applies ShortCoder (tools/ crate code_simplify()) on AgentResponse
       receipt, before forwarding to auditor view filesystem (tools.txt section 7).
     Stop fires on session termination or AgentKill sequence.
     PreCompact fires when orchestrator context budget allocator detects
       token_used / token_limit > 0.85 (handoff threshold, orchestrator.txt section 10).
  3. Tiered analysis findings feed violation_patterns (rules.txt section 6).
     Orchestrator normalizes findings to pattern hash — not the auditor (rules.txt section 6 step 1).
     PROPOSED rules from source=AUDITOR never auto-promote (rules.txt section 6 step 3e).
     Finding-source auditor cannot approve its own findings (rules.txt section 5).
  4. Error sanitization: hook verdicts (ALLOW/BLOCK/WARN) translated to generic
     IPC error responses. Agent sees "tool call rejected" not "PreToolUse BLOCK
     from rule trading.14" (orchestrator.txt section 12, plugins.txt section 3).
  5. T1 evaluates predicate DSL from rules.db (rules.txt section 3). 5 predicate
     types: AST_PATTERN, GREP_PATTERN, METRIC_GATE, COMPOSITE, SCHEMA_REQUIRED.
     T1 handles SCHEMA_REQUIRED by returning Escalate{target=ProviderTier} (not ALLOW
     or BLOCK — SCHEMA_REQUIRED requires provider-side constrained decoding, not T1).
     Plus implicit phase_mask filtering. T1 does NOT parse AST — that is T2.
  6. T3 fires only when (WARN exists) AND (no BLOCK exists). If T1=BLOCK and T2=WARN,
     T3 does NOT fire — the action is already blocked, T3 would waste 5ms on dead code.
  7. ruff has no public Rust library API (astral-sh/ruff #12351). PostToolUse ruff check
     is subprocess invocation (~50-200ms). Circuit breaker: skip ruff on files >10000 lines.
     PostToolUse total latency target: <500ms (dominated by ruff subprocess).
