PHASE 3D: BSP SUPERSTEPS + CHANNELS
  Goal: deterministic macro orchestration via BSP supersteps (Valiant 1990). Determinism guarantee
    holds in simulation mode (mocked agents, fixed seed). With live LLMs straggler timeouts can
    vary participation sets.
  Channel types (BinaryOp dropped — non-deterministic with concurrent writes):
    LastValue<T>: single value, last writer wins by SSB seq.
    Topic<T>(accumulate): true=persistent Vec<T>; false=two-phase reset (snapshot then clear
      AFTER snapshot, BEFORE execute_tasks writes).
    EphemeralValue<T>: per-superstep write_count (saturating_add). At barrier, count==0 → MISSING.
      Clearing recorded in SSB so crash recovery is replayable from SSB alone.
    UntrackedValue<T: DeepSizeOf>: in-memory only, never serialized. Force-clear when usage >
      2× limit (default 10MB). NEVER measure with std::mem::size_of_val (returns 24 bytes for Vec!).
  Steps:
    3D.1 channel types + ChannelRegistry trait (read, write, snapshot_for_scheduling,
        clear_ephemeral, force_clear_untracked, deep_size_untracked).
    3D.2 BSP loop: snapshot → prepare_next_tasks → clear_non_accumulating_topics → execute_tasks_parallel
        → apply_writes (sorted by SSB seq, deterministic) → deferred phase (3D.3) →
        clear_ephemeral → evidence_gate_check → save_checkpoint AFTER gate passes (BLOCK-4 fix:
        prevents filename collision on gate retry). Max superstep_attempts safety valve.
    3D.3 deferred nodes (LangGraph defer=True): NodeSpec.is_deferred fires post-barrier within
        same superstep, single pass only (no cascading), all_inputs_satisfied gate.
    3D.4 BSP checkpoint integration: HashMap<ChannelId, ChannelState> excluding UntrackedValue;
        memory_monitoring SSB action_type (NEW — keep distinct from isolation_metric).
        Crash recovery: load checkpoint, replay SSB entries (apply in seq order, count
        EphemeralValue writes per superstep, clear non-accumulating Topics at boundary).
    3D.5 spawn_parallel upgrade from Phase 3C stub: tokio::JoinSet with per-agent heartbeat
        timeout, VRAM-aware scheduling (max_concurrent = floor(available_vram / per_agent_vram)),
        results applied in SSB seq order (not completion order).

GENERAL ENGINEERING THEMES (cross-cutting throughout)
==============================================================================

Determinism / entropy quarantine: every phase enforces ClockProvider + EntropySource instead of
  raw std::time / thread_rng. Phase 0.9 establishes; Phase 3I proves via DST; Phase 3B/3D/3H
  re-verify under crash recovery. CI grep script + reference model + 100-run identity tests.

TDD red/green: every implementation phase writes failing tests BEFORE code (phase.N.3 TEST
  step) and only implements (phase.N.4 IMPLEMENT) once tests compile and fail correctly.

Anti-stale-training enforcement: blake3 over blake2s, tracing over log, thiserror/anyhow over
  Box<dyn Error>, deadpool over r2d2 for new code, globset over glob, etc. See CLAUDE.md.

Grounding hygiene: each phase has a GROUNDING block classifying every claim as GROUNDED /
  VERIFIED / UNGROUNDED with cited spec source. Test corpus + benchmark fixtures committed
  to git so claims are reproducible.

Phase-aware tool/rule filtering: enforced at ToolRegistry::execute level (NOT advisory). Hidden
  paths return NotFound identical to missing (Phase 3C / Phase 4A R31 mitigation — agent
  cannot distinguish hidden from nonexistent).

IPC + isolation: Phase 4A makes orchestrator authoritative for everything (GRC budget, LLM
  calls, tools, grounding). Agents are minimal binaries with NO network, NO LLM client,
  NO tools — all proxied via 15-message IPC protocol with 10MB hard frame cap.

Self-modification safety: rules with mutable=0 (security/finance) immune to auto-modification.
  Auditor-sourced rules stuck at PROPOSED until independent second auditor approves.
  Phase 4H restricts modifications to AllowedConfigKey enum (no source-code rewriting).

Phased graduation: INTERACTIVE in Phase 3, AUTONOMOUS opt-in in Phase 4G (no new FSM states,
  AutonomousGate wraps InteractiveGate). HIGH-risk gates and MAJOR replans pause in both modes.
