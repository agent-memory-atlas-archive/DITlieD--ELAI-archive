Dispatch core — canonical agent-dispatch machinery (HARD RULE)

Loaded by: every orchestrating skill (orchestrate, auto-orchestrate, b-plan-runner, idea-intake, paper-to-plan) and any session dispatching worker agents. This file is the SINGLE statement of the shared dispatch rules; the skills keep only their own trigger contracts and flow differentiators and POINT here instead of restating. (Origin: 2026-07-06 consolidation — the same four blocks were restated near-verbatim in three files; token-discipline: redundancy between files is a bug. orchestrate-protocol.md H-1..H-11 stays untouched and authoritative for its incident-born BLOCKING language.)

D-1 RULE INJECTION. Every agent prompt begins with the pointer line:
  "Read F:\.ELAI_workflow\.claude\rules\agent-dispatch-preamble.md FIRST and obey it as binding. handoff_file=<path>; task_id=<id>; scope=<paths>."
Sub-agents do not reliably load CLAUDE.md; the pointer is the guarantee. A dispatch without it is a protocol violation (origin: 2026-06-11 git reset --hard x8 incident). The preamble bans worker git mutation and destructive ops, locks scope, defines BLOCKED=handoff-entry + structured return, and binds the R-8/D-030 production-caller contract (executor wires the PRODUCTION_HOOK seam same-changeset + self-runs the wire checker; explorer names the exact seam; auditor re-runs off-agent).

D-2 MODEL LADDER. Cheapest tier that fits, per dispatch, never "session model for everything": haiku = bulk read/summarize; sonnet = ALL canonical .claude/agents/*.md dispatches (via subagent_type=general-purpose + "Read F:\.ELAI_workflow\.claude\agents\<name>.md and follow it strictly. <args>") and executors; opus/fable = the controller session only, never spawned without the user explicitly asking in the current message.

D-3 PARALLEL CAP 3 (hard, provider rate limit — user may lower, never raise). Independent dispatches go in ONE message up to 3; the rest queue. FLEET ANNOUNCEMENT: more than 2 agents in one go = announce count + models + rough token cost and get the user's yes FIRST; a plan-walk invocation ("orchestrate <plan>", "run B-N") is standing authorization for the canonical per-sub-phase fleet only.

D-4 SCOPED CONTEXT. A worker receives ONLY what its task needs: the task, relevant paths, the orchestrator-distilled slice of prior results, its handoff pointer. Never the full run state, never sibling raw output, never failed siblings' tracebacks.

D-5 HANDOFF MEDIATION LOOP. One topic-keyed handoff file per run (handoff-protocol.md). Worker hits a fork/blocker/banned-op/budget-pressure -> APPENDS an entry (SUMMARY / WORK DONE / FILES TOUCHED / QUESTION FOR ORCHESTRATOR / HOW TO PICK UP) and returns "BLOCKED: <question>". Orchestrator: (1) reads the ENTRY, not the whole file; (2) DECIDES — grounded in run evidence, a targeted read, or WebSearch; only tripwire-grade items go to the user; (3) appends a DECISION block under the entry; (4) the successor's prompt names the entry + DECISION. Workers never resolve material forks themselves; the loop is also the resume spec for context-exhausted agents.

D-6 EXECUTION/EVALUATION SEPARATION. The agent that verifies a task never authored it; workers never author or run the checks that judge their own output as the authority (wiring-enforcement R8 at orchestration grain; self-runs are courtesy, the auditor's off-agent re-run rules). A task flips DONE only on off-worker evidence: an independent checker agent, or a deterministic frozen-tool exit code. The worker's own "STATUS: DONE" is necessary, never sufficient.

D-7 INTEGRATION GATE (wiring-enforcement R10 — per-worker green is necessary, NEVER sufficient). Decompose in VERTICAL SLICES (producer + consumer + smoke same unit); THREAD cross-worker contracts on shared resources as required inputs; WIRE-CHECK every changeset off-agent (.rs -> production_caller_check.py, .py -> python_wire_check.py; DARK with no WIRE-DARK row = BLOCK); run an INTEGRATION SMOKE after every 2-3 units AND before the final report — an independent agent driving the REAL entrypoint on a HARD input (strict peer, multi-turn, long enough to fire secondary paths). Toy happy-path smokes do not count. The smoke units are in the task graph from the START (plan-standard.md point 10), never bolted on.

D-8 PLAN GATE PRE-FLIGHT (plan-standard.md). Before walking/executing ANY plan or decomposition: run python .claude/tools/plan_gate_check.py --file <plan>. FAIL -> refine-before-execute (planning-workflow "Plan improvement" injects the missing wargame blocks, re-gate, then execute). Only skip: explicit USER_OVERRIDE in the current message, logged.

D-9 LOOP PREVENTION. Re-dispatch cap 2 per task id with materially the same input; a third identical attempt is banned — change the decomposition or escalate. Monotonic progress check at every return: run state unchanged = that return was waste, diagnose before dispatching more. Anti-spiral triggers (same file >3 edits same issue, BLOCK twice in a row, 3 failed hypotheses) route to the anti-spiral skill.

D-10 GIT DISCIPLINE. Workers: git read-only (preamble R-1). Orchestrator: at most ONE commit at the very end per commit-cadence.md; destructive git only with explicit user Y/N; a confusing tree state is DIAGNOSED via reader agents, never "repaired" with resets.
