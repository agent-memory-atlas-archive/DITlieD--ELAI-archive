ELAI Dashboard

A Tauri 2 + Svelte 5 + Vite desktop application for ELAI — a Rust-native deterministic development engine. The dashboard surfaces FSM state, activity feeds, plan trees, review diffs, and system monitoring for a local-first AI coding agent with structured reasoning and gate-controlled execution.

Run:
  npm i && npm run tauri:dev
