D-16 — UniCR conformal-refusal calibration seed corpus.

This directory is the bootstrap source for `CalibrationCorpus::seed_*`.
The shipped `calibration_seed.jsonl` carries a tiny synthetic corpus
(~20 tuples, balanced positive/negative) used by the orchestrator's
integration test and the dashboard's smoke pass. It is NOT a substitute
for the live nightly-grown corpus that lives under
`.elai_cc/calibration/corpus/` once the TauUpdater starts emitting
production rows.

JSONL schema (one tuple per line; UTF-8, LF terminator):

  tuple_id        stable identifier (suffix `seed-<n>`).
  claim_id        the originating Claim id (synthetic for the seed).
  claim_text      bounded claim text (<= 256 chars).
  ground_truth    bool — whether the claim turned out to be true.
  predicted_score f64 in [0.0, 1.0] — composite confidence at decision
                  time (consumer side, NOT the source-of-truth).
  ts_ms           UNIX ms of the synthesized tuple.

Grounding:
  arXiv:2503.01345 (UniCR — unified conformal refusal).
  Vovk et al., Algorithmic Learning in a Random World (2005), §2.2
  quantile-based conformal predictor.

Policy notes:
  * `predicted_score = 0.0` means "model maximally uncertain"; high
    score = high confidence. The UniCR tau is computed on the
    `(1 - predicted_score)` non-conformity scores so the abstain
    region is the top-quantile of low-confidence claims.
  * The seed corpus is balanced 10 true / 10 false on purpose: the
    test that consumes it asserts that decide() with a near-zero
    predicted_score returns Abstain and a near-1.0 score returns
    Answer with the expected confidence.
  * Production corpus growth is the L3-locked TauUpdater's
    responsibility; the seed file is read-only for the orchestrator
    and may be regenerated by an L3_OVERRIDE follow-up patch.
