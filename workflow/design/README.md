# ELAI dashboard design archive

These are historical design proposals, prototypes and observations. They show
what the dashboard was intended to become; they do not establish a finished UI.

Start with the [user flows](dashboard-design-system/USER-FLOWS.md). Section 1.1
preserves the later accepted interaction model; superseded ideas remain labeled.
The [seven surface digests](dashboard-design-system/surface-digests/) connect
those flows to the master feature list.

The [design-system rebuild plan](dashboard-design-system/PLAN.md) proposes token
consolidation, lint gates and a component gallery. Its [335-finding baseline](dashboard-design-system/design-lint-baseline.json)
is a saved historical result with sanitized paths, not a newly run check.

- [Palette studies](palette-boards-2026-06-12.html), [progress study](canvas-progress-example-2026-06-12.html), and [harness studies](harness-ui/).
- Original concept boards: [phosphor instrument](cook-elai-renders/direction-A-phosphor-instrument.png), [engineer's ledger](cook-elai-renders/direction-B-engineers-ledger.png), and [deep chart](cook-elai-renders/direction-C-deep-chart.png).
- [External reference index](harness-references/INDEX.md). The third-party screenshots themselves are omitted.

none supplies the working agent backend pictured in the mockup. Original design
rulings and private-source references may describe superseded arrangements.
