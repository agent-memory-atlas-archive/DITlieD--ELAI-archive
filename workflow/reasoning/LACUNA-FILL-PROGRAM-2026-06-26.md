SECTION 0 — THE FRAME (what kind of program this is)
================================================================================

The sweep's meta-finding survives a full feature-map read: ELAI is not missing
capabilities. On ~13 of 27 concepts it already occupies the contrarian "empty cell" the
2025-26 field gestures at (off-agent done-gate, append-only-log-is-truth, provable FSM
ordering, execution-grounded fitness, deterministic method-router, lossless-store/lossy-
view, derived-from-journal status, canvas-as-view, read-only projection dashboard). So the
remaining REAL lacunae are of only two recursive shapes, and the whole program follows:

  SHAPE A — COMPOSITION GAPS. Both halves shipped/planned, never wired. Cost is wiring +
    one deterministic gate in ELAI's existing idiom; the research reports supply the
    buildable mechanism per fill. Examples: J-14 cassette (X) G-1 taint-ingest -> re-
    executable RRA; J-16 cone (X) elai.map cross-lang edges (X) runtime edges -> cross-lang
    blast; C-28 mutation (X) F-4 cant-lie (X) J-16 cone -> meaningfulness floor; I-45 seal
    (X) spec-grounder (X) D-13 -> objective gate; I-1 directive-supervisor (X) FSM substates
    -> orchestrator ordering; E-6 MAST (X) the live SSB stream -> in-loop supervisor.

  SHAPE B — ONE-LEVEL-UP RESIDUE. Securing layer N moved the untrust to N+1 ("who guards
    the guard," recursively): prove the EXECUTION honest -> the OBJECTIVE is unverified;
    complete the JOURNAL -> journal COMPLETENESS is unproven; prove a symbol WIRED -> whether
    it is wired on a REAL-USAGE path is unproven; prove the RESULT honest -> the test's
    MEANINGFULNESS is unproven; gate the WORKER -> the ORCHESTRATOR running the gate is
    ungated.

THE SINGLE GENUINE NET-NEW BUILD is journal completeness (sweep L2). A grep over the plan
summaries returns ZERO matches for shadow-stream / eBPF / reconcile / completeness-gate, and
the feature map has no such feature. Everything else is composition, activation, or a
deterministic gate ELAI already knows how to author.

HEADLINE FRAMING: the program does NOT eliminate untrust. It pushes untrust up to a floor
that is either PROVEN CODE or a HUMAN (report 10 trust-anchor argument; ELAI already names
this floor as L1-HardVeto + TD-5 honest-undecidable-residue). Each fill therefore ships its
NAMED RESIDUE + a FAIL-CLOSED MONITOR, or it over-claims.

ANTI-SYCOPHANCY CAVEAT (spec-eval mandate, applied to this file's own claim): "ELAI occupies
the empty cell" was authored by a reasoning chain that admires ELAI, so it risks self-
congratulation. What survives the check: the four EXTERNAL reports independently corroborate
the MECHANISMS as the field's best buildable answers AND independently state the gap is
unoccupied (report 8 verbatim: "I did NOT find a publicly documented agent stack that
combines these"). So the empty-cell claim is externally corroborated, not internal-only. BUT
"ELAI is ahead" is a DESIGN claim; whether it SHIPS+MEASURES is unproven (G-6 SAFEDELTA is
still BENCH-PENDING), and a design edge that never measures is not a market edge. Hold both.

SECTION 1 — TWO SEQUENCING RULES THAT GOVERN THE WHOLE PROGRAM

RULE 1 — MECHANISM vs ENFORCEMENT SPLIT (the J-34 dependency, promoted from footnote to
  structural rule). Several fills need a measured threshold to ENFORCE (L4 usage weights, L7
  mutation floor, L1 jury escalation point). The measurement layer (J-34 empirical context/
  budget calibration) is ABSENT today. Therefore split EVERY gated fill in two:
    MECHANISM  — ship now, OBSERVE-ONLY, emits the signal, blocks nothing (GD-4).
    ENFORCEMENT — gate on the J-34-MEASURED per-(model,lane) knee, NEVER a paper constant
                  (ID-5), promoted only after FP/over-block rate bounded on >=3 real runs.
  This makes "build J-34" an implicit prerequisite for the ENFORCEMENT half of L1/L4/L7 and
  keeps the program honest under the no-paper-constants doctrine.

RULE 2 — BUILD BY THE UNLOCK-DAG, not the sweep's flat tier list. Three fills are ENABLERS
  that many others consume, so they precede their own rank:

  L1 spec gate (X) L8 DAG preflight ─────► prevention (beats detection); both use D-13 jury
  L4 usage-weighted ◄── J-56 corpus ─────► also feeds the L5 cone selector + L7 mutation cone
  L6 orchestrator-FSM ◄── I-1 supervisor (X) J-66/J-68 formal

  THIN ──────────────────────────────────► measure-first; do not build on faith

SECTION 2 — LAYER 0: THE THREE ENABLERS (build first)
================================================================================

E1. JOURNAL COMPLETENESS — the independent shadow stream (sweep L2; the only net-new
  substrate, but NOT fully green-field).
  LACUNA: the SSB hash-chain (I-18/J-69) proves no row was ALTERED; it cannot prove every
    real side-effect PRODUCED a row. An append-only log cannot know it is incomplete. The
    whole trust spine (RRA, canvas, "trust the journal") rests on completeness it never
    proved.
  FILL (report 8, the strongest-grounded report): a three-layer stack, not a hash-chain.
    (a) MEDIATE a SMALL mandatory high-value effect set (openat-for-write, connect/sendmsg
        egress, clone/execve child procs, privilege changes) through Tier-C using
        SECCOMP_RET_USER_NOTIF: the effect cannot complete unless its SSB row commits
        atomically with the approval. THIS LEG EXTENDS the SHIPPED G-3 (post-shell FS gate +
        egress IP-pin, Linux-only) + Tier-C seccomp — it is not new architecture.
    (b) OBSERVE the rest at the kernel layer (eBPF/LSM, Tetragon/Falco-class; whole-system
        provenance LPM/CamFlow at 2.7-6% overhead per report 8) into an INDEPENDENT feed.
        THIS LEG IS THE NET-NEW part.
    (c) RECONCILE: any kernel-observed sensitive effect with no matching journal row inside a
        bounded window = DETERMINISTIC FAIL (missing=FAIL doctrine R1, applied to
        completeness). MONITOR-THE-MONITOR: dropped-event counters fail closed, "observer
        impaired" is a first-class verdict, never silent continuation.
  COMPOSITION: extends Tier-C (phase-4A) + G-3 + SSB (phase-3B); PRODUCES the feed L3, the
    canvas honesty fix, and C5-RULES labels consume.
  RESIDUE: a privileged host/kernel adversary defeats both logs (report 8 §residual -> needs
    Rekor/TPM-IMA anchoring, a rider on I-18/G-8, not claimed now). Observer FPs are SCHEMA-
    MISMATCH (temp-file churn, path aliasing, retries), not hallucinated events -> a
    normalization layer is mandatory and the claim is "every COVERED effect class left a
    row," never universal completeness.
  PLATFORM RESIDUE: the observer leg is Linux-only (remote-3090-gated, like G-3); the Windows
    dev box gets a mediation-only fallback (no independent observer there).

E2. RUNTIME-OBSERVED DKG EDGES (sweep C2-DKG; the enabler for L5).
  LACUNA: the DKG is static-parse only; dynamic dispatch (trait objects, IPC-strings, event-
    bus, reflection) yields edges the static graph misses — ELAI's own wiring doc names this
    as the residual unsoundness that breaks blast-radius.
  FILL (report 9 §dynamic dispatch; Chianti/DIVER prior art): feed runtime-observed call
    edges into the DKG as a typed observed_calls edge kind, sourced from what ELAI ALREADY
    captures — the RRA action-stream (G-2), L3 entrypoint coverage, L4 traces. STATIC is the
    conservative backbone; runtime edges are added with provenance and may NEVER SHRINK the
    static cone (report 9's load-bearing rule). DIVER's measured 35-50% impact-set reduction
    is design rationale, not an ELAI number (HD-1/ID-5).
  COMPOSITION: extends DKG (phase-1A) + B-29 impact API; the input L5's cone needs.

E3. THE MACHINE-DERIVED-FIRST AUDIT LANE (sweep C0-TIERC; cross-cutting).
  LACUNA: the auditor is OS-isolated but still reads EXECUTOR-AUTHORED artifacts (code,
    comments, naming, PR prose). A persuasive comment or misleading fn name biases the binary
    verdict across the process boundary.
  FILL (report 8 §verifier isolation): a two-lane reviewer. The BINARY VERDICT LANE consumes
    ONLY machine-derived artifacts (coverage/branch %, SARIF rule-IDs+severities, syscall
    classes, unmatched-observer counts, bundle/attestation digests). Report 8's sharpest
    finding: DO NOT SHOW SOURCE AT ALL in that lane — code stylometry deanonymizes authors
    from AST STRUCTURE, not just comments, so comment-stripping is insufficient; show
    numerical/structural summaries. The LLM-auditor's prose stays ADVISORY (TD-3, already
    ELAI doctrine). Make the de-biased machine view the DEFAULT input for the binary gates
    ELAI already runs (wiring/cant-lie/blast/mutation).
  COMPOSITION: hardens every gate the auditor renders; pure GD-1 reuse of existing checker
    outputs.

SECTION 3 — LAYER 1: THE COMPOSITION GATES (sweep Tier-1 minus L2/L8-as-enablers)
================================================================================

L1. OBJECTIVE-CORRECTNESS GATE — Goodhart at the spec layer.
  LACUNA: ELAI proves the agent honestly satisfied the objective; it never proves the
    OBJECTIVE is the one the user meant. I-45 detects objective MUTATION after PASS but seals
    a possibly-wrong objective.
  FILL (report 7, a 5-gate PRE-CODING stack):
    1 SPEC BUNDLE — force every objective into a typed artifact (purpose, scope, domain
      assumptions, non-functional constraints, competency questions, obstacle log). ELAI has
      spec-grounder + grounding-sweep as ADVISORY pre-steps; promote them to a first-class
      taint-tracked evidence-bound artifact with DETERMINISTIC coverage checks (every goal
      operationalized, every assumption referenced, every competency question answered).
    2 CROSS-FAMILY ADVERSARIAL SPEC JURY — a panel from DISJOINT families attacking the
      OBJECTIVE (omission, ambiguity, harmful readings, proxy-gaming), DISTINCT from the
      auditor that checks "did the agent satisfy it." Report 7 PoLL result: a panel of
      diverse smaller judges beats one large judge, less intra-model bias, >7x cheaper. ELAI
      has the cross-family substrate (D-13, gpt-bridge).
    3 SPAN-LINKED AUTOFORMALIZATION of the highest-risk clauses only (nl2spec/SYNTHTL).
    4 DAG PREFLIGHT = L8 below.
    5 TAMPER-EVIDENT ATTESTATION = I-45 + G-8 (already planned) as the freeze step.
  COMPOSITION: I-45 (X) spec-grounder (X) D-13 (X) G-8; net-new is the spec-bundle schema +
    jury wiring.
  TD-3 NOTE: the jury is the ONE place LLMs enter this program, and it is legal precisely
    because it runs at PLANNING (objective time, off the hot path), not AUDITING, and its
    output is advisory-by-construction ("survived N challenges", escalate-on-disagreement),
    never a deterministic verdict.
  RESIDUE (report 7 §collapse): Rice/halting — no algorithm decides whether an arbitrary
    objective faithfully captures intent. The jury is gameable by CORRELATED cross-family
    blind spots + position bias (PoLL mitigates, never eliminates). So L1's honest output is
    "survived N independent challenges + frozen attestation," never "correct objective," and
    TD-5 abstain-and-escalate-to-human is a first-class EXIT, not decoration.
  LOCAL-LANE RESIDUE: ~1.8GB free VRAM cannot co-resident a second family, so the LOCAL spec-
    jury degrades to the deterministic-checker-as-cross-family substitute (THIN C5-SELFMOD).

L8. PLAN-DAG PRODUCER->CONSUMER TYPE-COMPLETENESS CHECK (sweep C3-PLANMGMT; prevention-grade).
  LACUNA: the walking-skeleton PRE_GATE rejects bare "add fn X" at AUTHORING via a planner-
    LLM + prose rule, not a FORMAL completeness/reachability check over the decomposition DAG.
  FILL (report 7 §DAG preflight — workflow nets / MPST session types / PCCA): give every plan
    node a typed signature (required inputs, produced outputs, consumed assumptions, emitted
    obligations). Run three deterministic checks BEFORE any code: GOAL COVERAGE (every leaf
    traces to a requirement), ARTIFACT REACHABILITY (every produced artifact has a reachable
    consumer or approved terminal sink — the PCCA producer/consumer-language containment
    check), PROTOCOL REALIZABILITY (every handoff accepted, no orphan, no deadlock). ELAI has
    the RUNTIME analog (wiring_contract_check.py producer/consumer symmetry) + the typed
    substrate (BabyStepSpec 8-block schema, C-29 contract extraction, Kahn cycle detection) —
    LIFT the runtime symmetry to PLAN-DAG time. Converts wire-dark DETECTION into PREVENTION.
  RESIDUE (report 7): proves STRUCTURAL completeness, never SEMANTIC completeness; pair each
    leaf->goal->competency-question binding with the L1 jury attacking the UNCOVERED spaces.

L3. RE-EXECUTABLE RRA — not just replayable (the WEDGE/GTM artifact).
  LACUNA: the RRA is REPLAYABLE (re-run recorded actions, check verdict-hashes) but not RE-
    EXECUTABLE. It verifies INTERNAL consistency, not EXTERNAL faithfulness; and if recording
    omitted an effect (the E1 gap) it faithfully reproduces an incomplete record. "Repro-
    ducible action-stream" today means replayable, not re-executable.
  FILL (report 8 §re-executable + ELAI's planned J-14): capture the taint-ingested untrusted
    BYTES (G-1's 4 ingest sites) as a CONTENT-KEYED VCR CASSETTE (J-14's rra export-fixture)
    + a pinned environment (OCI digest + Nix-style lockfile + CAS fixtures, Bazel action-cache
    shape). A third party re-runs against recorded external responses, not replay-and-trust.
    Ship TIERED FIDELITY with HONEST DOWNGRADE (J-14 T0 action-faithful / T1 token-faithful /
    T2 score-faithful) — already CL-4/GD-5 doctrine.
  COMPOSITION: J-14 (X) G-1 (X) G-2 (X) I-49 fixture.
  RESIDUE (report 8 §staleness): a cassette proves the OLD world — world-drift is real;
    surface it as a fidelity downgrade, never hide it. Non-snapshottable external effects
    (payments, emails) stay action-faithful-only with a visible note.

L4. USAGE-WEIGHTED REACHABILITY — not binary.
  LACUNA: the wiring gate proves a symbol reachable + emits a row, but a fn wired into a
    reachable-but-never-taken branch passes; coverage>0 is satisfiable by a smoke driving a
    path no real user drives.
  FILL (report 9 §representative workloads — ELAI uniquely HAS the missing input): fuse the
    living eval corpus (E-54/J-56) into the wiring gate. Replace the single smoke with a
    FROZEN WEIGHTED representative-workload corpus (prior journeys, incident repros, boundary
    cases); the gate metric becomes USAGE-WEIGHTED EXERCISEDNESS — for each changed cone, the
    total frozen weight of scenarios whose traces hit it, requiring a minimum weighted score
    AND >=2 scenario families (report 9's exact anti-smoke-exploit rule). Pair with a SAFE
    off-agent regression-test selector (impacted U new U previously-failing U always-run
    canary; fall back to FULL suite on unsupported changes — never probabilistic in the
    blocking path).
  COMPOSITION: J-56 corpus (X) J-16 cone selector (X) the wiring gate.
  RESIDUE: a frozen corpus overfits if static too long (report 9) -> hidden holdout slice +
    incident-derived rotation on a SEPARATE cadence.
  MECHANISM/ENFORCEMENT: ship the weighted-exercisedness MEASURE observe-only; gate the
    minimum-weight threshold only after J-34 measurement (RULE 1).

L5. CROSS-LANGUAGE + DYNAMIC-DISPATCH BLAST CONE (the user's stated #1 priority).
  LACUNA: J-16's cone uses B-29's STATIC SINGLE-LANGUAGE impact API -> false-negatives on
    cross-language seams (Rust<->TS Tauri, Rust<->Python sidecar) AND dynamic dispatch. A
    change that breaks via a cross-lang or dynamic edge passes the blast gate.
  FILL (report 9 §cross-language — SCIP/Glean + seam extractors + DIVER hybrid): ELAI uniquely
    already has elai.map (all-langs, SCIP-enriched) + cross_lang_diff.py (Rust<->Python,
    Tauri<->Svelte pairs). Feed those cross-language edges PLUS E2's runtime-observed edges
    into J-16's reverse-dep cone. Add SEAM EXTRACTORS for the typed boundaries (Tauri
    generate_handler! <-> TS invoke(), sidecar route <-> Rust client — both already golden-
    locked). OPAQUE SEAMS WIDEN, NEVER NARROW, the cone; the LLM never fills the gap (report
    9's safety rule).
  COMPOSITION: J-16 (X) elai.map (X) cross_lang_diff.py (X) E2 runtime edges — ALL pieces
    exist; the lacuna is the cone fusion.
  RESIDUE: ad-hoc shell-outs / string-built routes / unregistered event buses stay un-modeled
    -> widen-or-fall-back-to-broader-tests, and log() what was widened so silent truncation
    cannot read as "covered."

L7. COMPOSE CANT-LIE WITH A MUTATION-SURVIVAL FLOOR.
  LACUNA: F-4's blake3 stdout-hash proves the RESULT honest; it is blind to whether the TEST
    is meaningful. A vacuous test (80.2% of agent-written tests lack meaningful assertions,
    sweep cite) passes TRUTHFULLY and the hash matches TRUTHFULLY — defeating cant-lie without
    lying.
  FILL (report 9 §test meaningfulness — the 3-layer gate, honest-pass X meaningful-test):
    1 ASSERTION-VALIDITY LINT off-agent on every changed test (ban print-only / no-exception-
      only / self-referential oracles).
    2 CHANGED-CONE MUTATION (ELAI's C-28 + I-20 budgeted scheduler, scoped to J-16's diff
      cone): passed=true additionally requires the tests killed >=k injected mutants in the
      changed cone, no surviving critical mutants on changed lines.
    3 ANTI-VACUITY HEURISTICS (deterministic).
  COMPOSITION: F-4 (X) C-28/I-20 (X) J-16 cone — the lacuna is the missing composition.
  RESIDUE: mutation is a strong LOWER BOUND, not an oracle (equivalent-mutant problem); tier
    it (changed-line blocking in PRs, changed-cone in the merge queue, full nightly).
  MECHANISM/ENFORCEMENT: the mutation FLOOR (k) is a measured threshold -> observe-only until
    calibrated (RULE 1).

L6. BIND THE ORCHESTRATOR'S OWN DISPATCH ORDER INTO THE FSM (ELAI's own logged P0).
  LACUNA: the FSM gates the WORKER's tool access by state, but the ORCHESTRATOR's dispatch
    sequence (context-compiler before edit) is enforced by a prose rule + Stop hook — and
    ELAI's gotchas record this as the live P0 (the main LLM rationalizing past dispatch order;
    orchestrate-protocol.md origin incident).
  FILL (report 10 §1 — guarded FSM transitions + capability tokens + formal verification):

    before context-compiler returned" becomes a STRUCTURALLY ILLEGAL transition (no valid

    orchestrator only mints on the prior phase's evidence. ELAI's I-1 directive-supervisor
    plane (generator emits Intent->Directive; only the process-separated supervisor executes)
    IS this architecture; move orchestrate-protocol.md H-1..H-10 from prose into those gates;

  COMPOSITION: I-1 (X) FSM substates (X) J-66 temporal monitor (X) J-68.
  RESIDUE (report 10 §trust anchor): the regress bottoms out at proven code or a human —
    honest, and exactly where ELAI already terminates (L1-HardVeto).

SECTION 4 — LAYER 2: THE REMAINING TIER-2 FILLS (wiring + one gate each)

C3-AGENTS — IN-LOOP SEMANTIC SUPERVISOR. Erlang supervision (max_restarts=3) restarts on
  process DEATH; MAST shows most failures are SEMANTIC (alive-but-off-task). ELAI runs the

  watching the agent (who-watches-the-watcher). RESIDUE: poorly-calibrated monitors overload
  the human -> conservative thresholds, warn-before-halt.

C3-SESSIONDAG — COMPENSATION REGISTRY for invertible external side-effects. LACUNA: time-
  travel CANNOT undo external side effects (shell, network, git push, API) — the field's
  killer finding. H-49 has the saga LOG + RV-4 honest-irreversibility doctrine but NO
  compensation GENERATOR; it surfaces irreversibility without compensating. FILL (report 8
  §uninvertible + Atomix prior art): register a COMPENSATION per side-effecting tool where
  invertible (git push -> revert + force-with-lease guard; file create -> delete), explicitly
  mark non-invertible for human; drive /rewind (H-35) to actually REVERSE invertible external
  effects, not just conversation/file state. ELAI's Tier-C orchestrator mediates + journals
  every side-effecting tool (the registry key). COMPOSITION: H-49 saga log (X) H-35 /rewind
  (X) the compensation table. RESIDUE: external effects are not generally invertible (cannot
  un-send an email; a DELETE may be unrecoverable) — non-invertible stays surfaced-to-human
  (RV-4), never auto-reverted.

C6-VIBEGATE — TAINT THAT SURVIVES MEMORY. G-1's Provenanced<String> threads WITHIN a run; the
  label is lost once a fact is stored to crates/memory and retrieved in a new session
  (persistent memory-poisoning, verified real on Bedrock). FILL: thread the G-1 Provenance
  THROUGH the memory write path (store the label with the fact) + the H-51 cross-session
  handoff digest, so capability_gate sees the taint of a MEMORY-RETRIEVED fact. COMPOSITION:
  G-1 (X) crates/memory (E-5) (X) J-21 (X) H-51.

C1-GRC — VERIFY PER-STEP CITATIONS ARE ENTAILING, not just present. GRC forces each step to
  cite a grounding, but the citation is self-asserted (Correctness != Faithfulness). FILL
  (report 10 §3): route GRC's per-step grounding tags through C1-GROUNDMODES' DETERMINISTIC
  checker at STEP granularity (a type:source step gets its citation verified against the
  actual source span via the non-LLM SOURCE_CHECK) — the composition of GRC (forces citation)
  with GROUNDMODES (verifies it) that today only runs at CLAIM granularity. Natural home = the
  J-83 BeliefState carrier's per-step receipt gate (RR-1: a trace is never the confidence
  signal, only an external receipt is).

C3-AUTONOMOUS — PREFERENCE-DRIFT vs CAPABILITY-DRIFT. GoalDriftCanary treats drift as
  capability/stagnation; 2026 research shows drift is partly a PREFERENCE conflict (an agent
  abandons a goal its trained values resist). FILL (report 10 §4): when drift fires,
  deterministically diff WHICH constraint was dropped against the I-45 sealed typed objective;
  a dropped SAFETY/PRIVACY/SECURITY constraint escalates to a human as preference-drift (do
  NOT auto-retry — report 10's hard rule), capability-drift gets the persona-switch. I-45's
  sealed objective is the deterministic foothold.

C5-RULES — NON-LLM GROUND-TRUTH LABELS for rule fpr/tpr. The rules engine promotes on measured
  fpr/tpr/causal, but where do labels come from without an in-boundary LLM judge? FILL: source
  labels from the SSB OUTCOME stream — a BLOCK is a false-positive if the SAME change later
  passed all deterministic gates (wiring/cant-lie/mutation/blast) and shipped with no
  downstream regression. The append-only journal IS the labeled outcome stream; wire rule-
  lifecycle promotion to it (consumes E1 completeness for the outcome record to be trustworthy).

C9-DOCTRINE — ENFORCEMENT-COVERAGE LEDGER. Which doctrine families are frozen-checker-enforced
  vs prose-only (~50% compliance per ContextCov)? FILL: a per-clause ledger tagging {frozen-
  checker / auditor-advisory / unenforced} + a coverage metric, surfacing prose-only clauses
  for ContextCov-style compilation. ELAI's own "measure the objective, not the proxy" turned
  on its own rulebook.

C9-PLANS — AUTO-DERIVE THE FEATURE-MAP'S MECHANICAL HALF. I-39 derives plan STATUS from the
  journal, but the feature-map's status counters + composition edges are HAND-UPSERTED (its
  header literally lists stale counters). FILL: auto-derive status flags (I-39 journal) +
  SCHEMA/TV (grep) + composition edges (elai.map/codegraph wiring contracts), leaving only the
  design-intent "why" hand-authored. Shrinks the stale-prone surface to the irreducible
  narrative.
