## 0. VERDICT UP FRONT

Do not build a monolithic "Novelty Engine". The investigation separated novelty into two testable
controller hypotheses, and both failed their own promotion gates:

- FRONTIER PLANE (REFUTED AS A CONTROLLER BY B-3) — tested archive-aimed generation through
  explicit cross-cycle variation operators against freestyle-with-memory.
- DISCRIMINATION PLANE (REFUTED BY B-0) — tested deterministic probe selection by
  hypothesis-splitting power per unit cost against a strong model choosing its own next test.

GRC/CGG stay untouched as the correctness plane ("what may we believe/act on" / "did X cause Y").
Neither failed controller becomes their novelty-axis sibling. The surviving conjecture-engine
upgrade is deliberately smaller: it keeps its proven identity as a grounding machine (3.5x real
anchors), folds an append-only harness archive, reports archive-relative novelty as an unfused axis,
records typed provenance/status, and exposes declared pick profiles. Only the `NOVEL-CREDIBLE`
selector has a positive novelty result; it does not establish autonomous frontier discovery.

D5 VALUE IS DECIDED BY EXECUTION, NEVER JUDGE BET (seed C5, unchanged). The value leg of any FDL

D6 NOTHING NOVEL IS DELETED (seed C6, unchanged). Losers land in the harness archive with computed

   Cross-task stepping stones (a refuted mechanism from problem A parenting a win on problem B) are

D7 THE ARCHIVE IS NOT THE CONTEXT (new; PACEvolve lesson, frontier §12.3). "Remembered" must never

   narratives. The rule in four lines: RAW_ARCHIVE_TEXT banned; STRUCTURED_PARENT_STATE allowed,

   (Adversarial-review patch 2026-07-12: the original blanket ban contradicted the §4 operator

D8 THE GENERATOR NEVER OWNS EPISTEMIC STATUS (new; frontier pillar 3 + L-24 doctrine). A candidate
   carries claimant-authored PREDICTIONS; observations enter through executed probes; status
   (live/refuted/pending/suspended/validated) is a pure fold over prediction-vs-observation matching
   rules + kill/birth edges. No model prose ever writes a status field.

D9 REFUTED CONTROLLER SPEC — DISCRIMINATE BEFORE BLINDLY GENERATING MORE (B-0; retained to record
   the tested hypothesis). The design was gated, never absolute (adversarial-review patch
   2026-07-12: a hard DISCRIMINATE > EXPAND rule walks into the closed-world trap — ten elegant
   probes can prove H2 is the least wrong member of an entirely wrong hypothesis set). A COVERAGE
   GATE runs first; discriminate only when (a) the live set has mechanism diversity (>=2 distinct
   meaning clusters), (b) at least one live candidate explains every major observation, and (c) a
   probe exists with utility above the caller floor — otherwise the next budget unit is EXPAND
   (or REFRAME when the fade guard says the frame is spent). Probe utility = split-power x
   observation-reliability / cost; the L0>L1>L2>L3 ladder sets the RELIABILITY term only and
   never overrides cost (a "perfect" 24-hour L0 benchmark loses to a 2-second grep that kills 80%
   of the pairs): L0 deterministic elimination, L1 categorical prediction-partition, L2
   empirically-calibrated probabilities (ONLY where ELAI's own journal provides frequencies for
   that probe class), L3 Bayesian EIG (DEFERRED: LLM-hallucinated P(O|H) under deterministic math
   is garbage-in — the frontier session's §12.6 correction, adopted). HYPOTHESIS EXHAUSTION is
   NOT FRAME FAILURE: all-candidates-refuted means FIRST "the correct hypothesis is missing" (one
   EXPAND round inside the same frame); only a refuted expansion round escalates to reframe. B-0's
   objective-per-cost tie killed this controller, so none of these scheduling rules are live.

D10 TESTED OBJECTIVE, NOT SHIPPED DOCTRINE (frontier pillar 4; refuted implementation). The
   proposed controller objective across cycles was expected search progress: new validated mechanism
   families, killed hypotheses, closed discriminators — not "best single answer now". B-3 measured
   that objective and found lower frontier yield than control, so operator credit (§4) remains a
   benchmark analysis field only. This was the doctrinal line intended to make FDL an offensive
   system rather than the corpus's existing defensive anti-stagnation machinery.

## 3. THE HARNESS ARCHIVE — persistent typed search state

Unit = the CANDIDATE ROW, extending the existing conjecture card (all existing fields keep their
names so v1.0 artifacts remain parseable):

  existing: id, mechanism_family, target_area, target_units, expected_effect, cost_class,
            falsifier, bin, typicality, proof_spine, external_claims
  new:      operator            (which variation operator birthed it — closed vocab §4)
            frame               (the problem representation it lives under; default = trigger-as-given)
            parents             (candidate-ids it mutated/recombined from, or none)
            predictions         (claimant-authored observable predictions, >=1; the falsifier is
                                 prediction #1 — same object, two lifecycle points, per L-22)
            novelty_axis        (equivalence verdict vs nearest archive mechanism: neighbor id +
                                 SAME|DISTINCT|UNCERTAIN + judge votes + instrument version — see
                                 the instrument note below; any scalar is derived, never stored)
            status              (computed, never written by a generator: live | refuted | pending |
                                 suspended | validated; L-24 fold semantics — refuting a premise
                                 SUSPENDS dependents, no status is absorbing)

Edge grammar (append-only, greppable, line-start; extends the existing KILL-EDGE grammar):
  BIRTH-EDGE: <cid> <- <operator>:<params-or-parent-ids>     (provenance; every candidate has one)
  KILL-EDGE:  <cid> <- <killer-type>:<stable-ref>            (unchanged from v1.0)
  INJECT:     <cid> <- <exogenous-source>:<stable-ref>       (what world-bits conditioned its birth)
  PROBE-EDGE: <probe-id> -> <cid>:<predicted>|<observed>     (discrimination results; the status
                                                              fold's input)

The archive INDEX is a fold, not a curated document: a script walks
workflow/reasoning/conjecture-run-*.md + frontier-run-*.md, recomputes bins, statuses, operator
credit, and meaning-clusters, and emits frontier-archive-index.json (+ a human .md view). Nothing
hand-edits the index; a later session re-checks losers exactly as today (grep KILL-EDGE, reinstate
when the killer changed). Novelty instrument (adversarial-review patch: NLI clustering is an
INSTRUMENT, not a metric — no symmetry, no triangle inequality, cluster ids drift as the archive
grows): the TRUTH OBJECT per candidate is an EQUIVALENCE VERDICT against the nearest archive
mechanism, never a distance scalar — {nearest_known_mechanism: <id>, equivalence: SAME | DISTINCT
| UNCERTAIN, judge_votes: n/m, instrument_version: <id>} — produced by the L-4/F-12 NLI meaning-
cluster machinery with 2 seeded orderings and the spread REPORTED (the ±1-2 ordering noise is a
measured instrument property, never hidden). Archive coverage folds from the versioned mechanism-
equivalence graph these verdicts form; a scalar novelty score MAY be derived for ranking but is
heuristic, labeled, and never stored as truth. Deterministic fallback when no judge is available =
bin-coordinate distance (weak, labeled as such in the artifact).

## 4. THE OPERATOR PORTFOLIO + CREDIT LEDGER (v0 policy — REFUTED BY B-3)

Closed operator vocabulary (extensible per run with an explicit declaration, like mechanism_family):

  direct        one-call N-distinct generation (the strong baseline; ALWAYS kept as an arm)
  mutate        change exactly one mechanism element of a parent candidate
  recombine     hybridize mechanisms from two parents (cross-bin parents preferred)
  reframe       restate the trigger as a different problem class; generate under the new frame
  analogize     transplant the mechanism of a structurally-similar problem from a distant domain
  invert        negate a load-bearing assumption; generate only what makes sense under the negation
  tail-explore  VS-style low-typicality sampling (typicality self-report kept from v1.0)
  exo-inject    condition on a retrieved artifact (code slice, paper claim, bench row) — D1(a)
  cross-family  same prompt, genuinely different model family (D-13 rail) — D1(a)

The closed vocabulary and BIRTH-EDGE provenance remain useful descriptive fields in v1.1 artifacts.
The following allocation controller was the tested hypothesis and MUST NOT be promoted. It proposed
that every generation call be operator-typed and that OPERATOR CREDIT be a mechanical fold over the
archive: per (operator x problem-class), the rates of
{novel-at-birth, survived-triage, validated-by-execution} and cost. Allocation policy versioned in
the artifact, revised by the §6 measurement: v0 SINGLE-SHOT = direct only (one self-coordinating
call; the measured strongest set-diversity generator) + empty-bin targeting + exo-inject where an
artifact exists; v0 MULTI-CYCLE = operator calls fire only WITH ARCHIVE PARENTS (mutate/recombine/
reframe conditioned on archived candidates; recombine first per the §6 attribution, tail-explore
last), round-robin within that set plus the fade guard below; v1 (only after >=30 archived
candidates per cell) = credit-weighted; a contextual bandit is DEFERRED until the credit table has
non-toy support (frontier §5.8's bandit adopted as a later rung, not v0 — small-sample bandits
overfit noise). CREDIT IS CONFOUNDED UNTIL DESIGNED OTHERWISE (adversarial-review patch): operator
assignment is never random (recombine gets promising parents, reframe fires after failures), so
raw per-operator validation rates are selection-biased. Every BIRTH-EDGE therefore logs its
context covariates (model+version, problem class, parent status/quality, archive depth,
failed-cycle count, budget), and v0 allocation inserts OCCASIONAL RANDOMIZED operator assignment
within comparable situations, so a future credit-weighted policy would learn from something other
than its own selection bias (composes the N-plan anti-selection-bias primitives, never forks them).
B-3 refuted the prerequisite multi-cycle policy before any v1 credit weighting existed. The credit
rows may be analyzed from benchmark artifacts; no allocator, fade controller, or runtime bridge ships.

FADE GUARD (tested design only; not shipped; composes S2/C-10, does not fork them): track new-meaning-cluster rate per
cycle; when it drops below the caller-declared floor for 2 consecutive cycles, force in order:
(1) rotate to the least-recently-used operator class, (2) switch frame, (3) problem turnover
(archive the trigger as exhausted-for-now — I-8/I-26 semantics). The DeepReason F3 result (fast
rotation beats slow under fade) is the receipt that rotation belongs at the FADE grain, not inside
a single shot (where it measured null).

CONTROL ARM USED BY THE BENCHMARK — PAIRED ON THE SAME TRIGGER (GD-2
posture; wording hardened after the adversarial review read it as unpaired): every Nth trigger
(default N=5) runs BOTH arms on that SAME trigger — same model, same budget, same external-info
access, arm order randomized — so trigger difficulty cancels within the pair, and the paired
delta is appended to the artifact. Never a design where control triggers are DIFFERENT triggers
(an unlucky hard control trigger would flatter the treatment). The FDL's headline numbers are
therefore reproducible from the saved benchmark artifacts rather than allowed to drift into folklore.

## 5. THE DISCRIMINATION ENGINE (v0 spec — REFUTED BY B-0; retained as the tested hypothesis)

Input: >=2 live candidates (hypotheses, steal options, bug causes, design forks) each carrying
predictions. v0 is harness-side and deliberately dumb-deterministic:

  1 TABLE    build the candidate x probe prediction table. A probe is a runnable observation
             (grep/command/script/bench-row read/WebSearch) with a cost class {S,M,L}. Each cell is
             a CATEGORICAL predicted outcome (no probabilities in v0 — D9).
  2 SCORE    ProbeUtility = pairs-split x observation-reliability / cost-weight (reliability from
             the D9 ladder: deterministic > categorical > calibrated; the ladder never overrides
             cost). Short-circuit only for a fully-disjoint probe of cost class S — a fully-
             disjoint 24-hour benchmark still queues behind a 2-second grep that kills 80% of the
             pairs (adversarial-review patch).
  3 EXECUTE  run the top probe with real tools; journal the raw observation + hash.
  4 UPDATE   per candidate: prediction-vs-observation MATCHING RULE (declared with the prediction,
             e.g. "symbol exists", "exit 0", "count > N") -> PROBE-EDGE rows -> status fold. A
             candidate with no matching rule for a run probe stays pending (it predicted nothing —
             that itself is signal; forbids-nothing candidates are already auto-rejected at birth).
  5 REPEAT   until one survivor / caller evidence bar / budget. All candidates refuted =
             HYPOTHESIS EXHAUSTION, not frame failure: one EXPAND round inside the SAME frame
             first (the correct hypothesis was probably missing); reframe back to the FRONTIER
             plane only when that expansion round is also refuted or the fade guard independently
             fires (the D9 split). The D9 coverage gate runs before every cycle of this loop.

L2 (empirical probabilities from ELAI's own journal frequencies) and L3 (Bayesian EIG) are gated
behind measured calibration data existing — RECON at that future plan's authoring, not now.
The v0 falsifier (§8, B-0) tests the deepest claim cheaply — and against the RIGHT baseline: does
prediction-table probe scheduling beat a strong model directly choosing its next test, on real
task success per cost (not on hypotheses-killed, which is a proxy)? If that fails, the plane and
L2/L3 die unbuilt (correct order).
