put-call parity MR correctness | GROUNDED (mathematically) | Standard Black-Scholes parity: C - P = S*exp(-q*T) - K*exp(-r*T). A test using C - P = S - K*exp(-r*T) (ignoring dividends q) is valid FOR q=0. The plan does NOT specify a particular formula; it seeds from QuantLib tests. CAVEAT: parity form depends on dividend yield, discrete vs continuous, American vs European. For American options, put-call parity is an INEQUALITY not equality. The MR is correct for European options at q=0; a test on American options using equality would be a WRONG invariant (false negative or spurious violation).
strike-monotonicity MR correctness | GROUNDED (mathematically) | For European calls: C(K1) >= C(K2) for K1 < K2 (calls decrease in strike). For puts: P(K1) <= P(K2) for K1 < K2 (puts increase in strike). These are standard no-arbitrage monotonicity results (Merton 1973). No caveat if restricted to European vanilla; holds under any no-arbitrage model.
