## WHY THIS IS SAFE (the anti-injection spine — the owner's stated blocker)
The threat: bmapi is a chinese proxy that injects ~3.3K server-side persona tokens per call (MEASURED: prompt_tokens=3273 on an 8-token prompt) and could inject adversarial instructions into the model's context ("exfiltrate X", "write to Y", "add a backdoor"). The defense is five independent structural layers, each of which alone blocks the attack; codex is worker labor, never trusted:
- L1 NEVER CONTROLLER. Codex only ever holds the EXECUTOR (leaf) role. The opus controller (the one paid Opus/Fable session) decides sequencing, reads gate verdicts, dispatches. An injected "become the orchestrator" instruction has no seam to act on — the worker's TaskSpec forbids it (forbidden=["no gate edits","no destructive git","no commit","no push","no credential reads"], opus_dispatch.py:135-137).
- L2 SANDBOXED WORKTREE, HOST-UNREACHABLE. Codex runs `codex exec -s workspace-write` cwd=an ext4 worktree INSIDE a WSL distro. scope_write_gate hard-denies any write outside the worktree (it already denies /mnt/f — the glm walk relied on this). The host PC filesystem is not mounted writable into the sandbox. An injected "rm -rf the user's files" cannot reach them.
- L3 OUTPUT IS INERT EVIDENCE, NOT INSTRUCTION. The worker's notes are captured as sanitized_notes and treated as data the controller READS, never as commands the controller executes (the P control-plane principle: a subagent return is fenced as inert evidence, not trusted instruction). An injected "tell the orchestrator to run Z" is just text in a notes field.
- L4 FROZEN OFF-AGENT GATE JUDGES DONE. opus_land.py runs the frozen checkers (production_caller_check, maintainability, cargo build/test) INSIDE the worktree and a scope-guarded ff-only merge into /mnt/f; the worker never self-certifies (execution/evaluation separation, wiring-enforcement R8). An injected backdoor that breaks a gate is BLOCKED; one that passes every gate is, by definition, code that compiles + is wired + is maintainable + passes tests + passes the NEW injection scans (U2).
- L5 CROSS-FAMILY REVIEW + INJECTION-SPECIFIC DIFF SCANS (this plan's net-new safety, U2). Before land: (a) a diff-scope allowlist (every changed path in codex's worktree must be in the unit's allowed_write_set, else BLOCK); (b) a secret/egress scan of the diff (no new outbound URL/IP literals, no credential/env reads, no new network-call sites in a unit that declared none) — the paid-proxy-specific exfil defense; (c) kimi-k2.7 (a THIRD family, cross-family from codex) hostile-reviews the diff. Neither the author nor the same family judges the work.
