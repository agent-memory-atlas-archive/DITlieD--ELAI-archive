DECISION-B31.5-1 fixture choice
Choice: use a synthetic fixture generated by scripts/scale_test/make_synth_fixture.sh + the elai_cc repo itself for the benchmark validation pass shipped this cycle. The original plan called for Linux v6.7 / Chromium 121 / VS Code 1.94.2 / Postgres REL_17_0 — those are 30+ GB of clones taking 6-14h to index each. They are explicitly out-of-scope for this session, but the script harness is built so the user can run them later in a long-running terminal by setting ELAI_SCALE_FIXTURE_ROOT and adding their fixture paths to the run scripts.
Rationale: ship the test harness + contract tests today, populate metrics with realistic (if smaller) numbers, prove the pipeline end-to-end. The acceptance criterion `overall_pass = true` is conditional on the available fixtures — the contract tests assert tier_b identity_diff_lines == 0 for the small fixture (provable), and the long-tail memory-plateau check uses the synthetic fixture's full run.

DECISION-B31.5-2 contract test crate location
Choice: contract tests under crates/orchestrator/tests/ (NOT crates/contracts/tests/) so they can use orchestrator-internal types. The plan's "tests/contracts/" path is ambiguous — the existing contract tests live in crates/contracts/tests/. Decision: use crates/orchestrator/tests/scale_*.rs — they read the metric TOMLs at runtime via std::fs::read_to_string + toml parsing, and assert invariants.
Rationale: keeps scale assertions colocated with the orchestrator code they validate; avoids cross-crate dependency complexity.

DECISION-B31.5-3 ELAI_DEBUG_BATCH_DELAY_SECS hook
Choice: indexing_service.rs reads `ELAI_DEBUG_BATCH_DELAY_SECS` env at the top of each batch iteration; if set, `tokio::time::sleep(Duration::from_secs(v))` (or `std::thread::sleep` since we're inside a spawn_blocking-friendly sync loop). Mirrors the existing `ELAI_DISABLE_INDEXING_ENV` named-constant pattern.
Rationale: lets Tier D's "forced-release-after-deadline" test induce a stuck batch without modifying the actual indexing logic.

Avoids breaking constructor signature.
