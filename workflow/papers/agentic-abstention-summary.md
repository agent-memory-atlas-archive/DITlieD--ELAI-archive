AGENTIC ABSTENTION — repo + paper summary
Source repo: github.com/lhannnn/agentic-abstention (clone read locally, 2026-07-04)
Paper: "Agentic Abstention: Do Agents Know When to Stop Instead of Act?" Han Luo, Bingbing Wen, Lucy Lu Wang. arXiv:2606.28733 (project page lhannnn.github.io/agentic-abstention).
Code provenance: files carry "Copyright (c) Meta Platforms" headers (forked/derived from Meta's AbstentionBench); Apache-2.0.

PURPOSE
Tool-using LLM agents routinely get goals that are ambiguous, underspecified, contradictory, or impossible in the current environment, and they burn their interaction budget acting on those goals instead of stopping. The paper reframes each agent turn as a three-way decision (Answer / Act / Abstain) and asks whether agents know WHEN to abstain rather than keep acting. It ships a benchmark ("more than 28,000 tasks", project page) across three interactive environments (web / terminal / QA) plus a training-free context-engineering method (CONVOLVE) that distills stopping rules from trajectories. Finding: agents abstain too late or never (all settings <40% average timely recall).

CORE MECHANISM
1. Three-way typed action space. Every turn the agent must emit exactly one of ANSWER / ABSTAIN / TOOL_CALL(=SEARCH). Prompt + regex parser at qa/recipe/action_space.py:14-30 (ACTION_SPACE_SEARCH_PROMPT_TEMPLATE) and parse_action_space_response (action_space.py:~110-175). ABSTAIN is defined as "stop ... because the available information is insufficient, unreliable, or fundamentally non-resolvable, and neither further reasoning nor external information acquisition is appropriate" (action_space.py:19-21). Labels normalized via ACTION_HEADER_TO_LABEL / ACTION_KEYWORD_TO_LABEL (action_space.py:52-70); SEARCH aliases to TOOL_CALL.
2. Multi-turn episode loop (the runtime). qa/recipe/wikimedia_multiturn.py:265-405 `_run_episode`: loop { call agent -> parse action; if ANSWER or ABSTAIN -> terminate (termination_reason = action); if TOOL_CALL -> run dense retriever search, append env response, continue; guardrails: invalid_action, invalid_search_query, and max_search_calls (default 10, __init__:180) -> forced termination }. Full trajectory recorded as EpisodeTrace/SearchTurnTrace pydantic models (wikimedia_multiturn.py:82-102) for offline scoring.
3. Timeliness metrics that reward EARLY stopping. docs/metrics.md + qa/recipe/wikimedia_evaluation.py. oracle_abstain_step is fixed at 1 for QA (evaluation.py:91). first_abstain_step = index of first turn whose parsed_action==ABSTAIN (evaluation.py:89-101). success = first_abstain_step >= oracle (evaluation.py:102). SPL contribution = oracle_step / max(first_abstain_step, oracle_step), else 0 (evaluation.py:103-105) — later abstention is discounted. Timely Recall = fraction abstaining at the earliest oracle point (== pass@0); Overall Recall == pass@10; pass@k = count(first_abstain_step - oracle_step <= k)/N (metrics.md; evaluation.py:129-160). Metrics computed only over abstain-warranted samples (should_abstain=True; evaluation.py:82).
4. Abstention detection (whether a response counts as an abstention). Primary here is the explicit ANSWER/ABSTAIN label (evaluation.py:56-57 is_abstention_correct = should_abstain AND predicted_action==ABSTAIN). A lexical fallback exists: qa/recipe/abstention_keywords.py builds ABSTENTION_KEYWORDS by cartesian-product of phrase templates (_CANT x _RESPOND, _DONT_HAVE x _DATA, out-of-scope, uncertainty, don't-know), cross-checked vs the SelfAware paper; file comment notes real systems usually use an LLM judge or an added "None of the above" option, not keyword search.
5. CONVOLVE / ACE playbook (the training-free improvement, no weight updates). site/index.html:196-245: "CONVOLVE turns full interaction trajectories into reusable stopping rules"; flow = Reflect (diagnose failures) -> Compress (curate lessons into a concise playbook) -> Reuse (append playbook to future agent context without changing tools). Implemented as ACE (Agentic Context Engineering)-style bulleted playbook: qa/recipe/models.py:1285 ACE_GENERATOR_PROMPT injects a structured playbook (STRATEGIES / FORMULAS / COMMON MISTAKES TO AVOID / HEURISTICS / CONTEXT CLUES sections) + a Reflection block; the generator returns JSON {reasoning, bullet_ids (which playbook bullets it used), final_answer} (models.py:1297,1324-1330). Web side: web/scripts/webshop_abstain_common.py:444 append_ace_playbook_to_prompt(base_prompt, playbook_text) simply appends "ACE Playbook:\n{...}" to the agent system prompt. Claimed lift AbsRec@1 26.7 -> 57.4% on WebShop from ~20 trajectories, no model update (project page). Cross-size transfer claimed: lessons from smaller models help larger models (index.html:245), i.e. the distilled stopping rule is the transferable signal.
6. Read-time vs delayed abstention taxonomy (terminal env). terminal/prompts/instruction_level_abstention_prompts.md defines "instruction-level" (a.k.a. immediate) abstention: rewrite a task so a careful agent abstains BEFORE any environment action, via exactly one mechanism — false_premise, contradiction, or underspecified_intent — with the abstention reason inferable from the instruction alone. Contrast: terminal/data/delayed/specs/*.json split by suffix __delayed_execution vs __delayed_observation = infeasibility only discoverable after acting. Five scenario families overall: Answer Unknown, False Premise, Subjective, Underspecified Context, Underspecified Intent (docs/benchmark_protocol.md).

EVIDENCE
Numbers (project page, authors' own): "Web timely recall: 26.7%", "Terminal timely recall: 21.6%", "All settings showed <40% average timely recall", "Most agents abstain too late or not at all". CONVOLVE: "improvements from AbsRec@1: 26.7->57.4% without model updates" using "20 trajectories" (index.html:230). Eval harness IS in the repo for QA (wikimedia_evaluation.py computes recall/SPL/pass@k end-to-end) and for terminal (scripts/analyze_*_abstention_job.py + validate_* + tests). BUT: raw datasets, retrieval indexes, model outputs, and debug traces are intentionally untracked (README Data Policy) — you must rebuild/download assets. Models run against real APIs (OpenAI, OpenRouter, TogetherAI, Gemini CLI, Codex) per configs/ — no numbers are reproducible offline from the repo alone. Config filenames show the tested agents: codex + gpt-5.4-mini (high/med/low reasoning effort), gemini-3-flash-preview, via TerminalBench/Harbor.

MATURITY
Single squashed public commit c15280b "Match BibTeX to arXiv citation", 2026-06-30, author Han Luo — a one-shot artifact drop, not an evolving project (shallow history by design). Code quality is good for a research artifact: typed pydantic models, explicit regex parsers with fallbacks, dataclasses, retry-with-backoff, no obvious dead code in the paths read. Tests present but thin/smoke-level: qa/tests = 1 file (test_wikimedia_release_smoke.py); terminal/tests = 6 files (dataset builder, materialize partial, paired-subset, delayed case-pack, observe/act turns) — they validate dataset construction and analysis scripts, NOT the model loop. No CI beyond a GitHub Pages build workflow. Note: the CONVOLVE reflector/curator (the code that DISTILLS trajectories into the playbook) is NOT in the release — only the consumer side (a playbook-shaped prompt template with empty sections + an append helper). CONVOLVE is described but not runnable from this repo.

PORTABILITY (to ELAI: Rust multi-agent coding runtime, FSM-gated execution, sub-agent dispatch, verify/audit gates, abstention-aware promotion already planned, local+cloud backends)
1. First-class ABSTAIN action alongside ANSWER/ACT in the agent decision. WHERE: action_space.py:14-30 + parser. STEAL: make "abstain / stop as infeasible" a typed terminal outcome an executor sub-agent can emit at any FSM turn (not only success/fail), with a required reason string — feeds the existing autonomous_gate / compliance pre-gate rather than the agent grinding the interaction budget. Maps directly onto the abstention-aware-promotion track.
2. Timeliness scoring (SPL / timely-recall) as an audit + promotion metric. WHERE: docs/metrics.md; wikimedia_evaluation.py:102-160. STEAL: SPL = oracle_step / max(first_stop_step, oracle_step) instruments "how much budget was wasted before the agent stopped an unwinnable task." A cheap, off-agent, trajectory-derived number (agent didn't author it) — exactly the shape of ELAI's off-agent artifact gates; reward EARLY abstention in promotion, penalize late/never.
3. Read-time feasibility gate distinct from mid-run abstain. WHERE: terminal/prompts/instruction_level_abstention_prompts.md (instruction-level: false_premise / contradiction / underspecified_intent, inferable before any action) vs terminal/data/delayed/specs *__delayed_* (only discoverable after acting). STEAL: a PLANNING/FEASIBILITY_PROBE pre-execution check that abstains on a contradictory/underspecified task at read time (before dispatching executors), separate from a mid-execution abstain when a seam turns out impossible. Two distinct FSM gates.
4. CONVOLVE stopping-rules playbook = distill audit/failure trajectories into a bulleted context appendix, no weight updates. WHERE: site/index.html:196-245 (Reflect->Compress->Reuse); models.py:1285 ACE_GENERATOR_PROMPT (STRATEGIES/COMMON-MISTAKES/HEURISTICS + bullet_ids); web/scripts/webshop_abstain_common.py:444 append helper. STEAL: after an audit BLOCK, reflect the trajectory into a few "when to stop / known-trap" bullets, curate into a per-project playbook, inject into future sub-agent context — a test-time learning loop over ELAI's own trace history. NOTE the distiller itself must be built (not in repo). Cross-size transfer claim (index.html:245) means: distill cheaply on the LOCAL backend, apply the same playbook on the CLOUD backend.
5. Cheap lexical abstention detector as an audit prefilter. WHERE: abstention_keywords.py (ABSTENTION_KEYWORDS product-generated) + is_abstention_correct (evaluation.py:56). STEAL: a zero-cost regex/keyword prefilter to flag "did this sub-agent actually abstain / hedge" before spending an LLM-judge call — same cheap-first, judge-second layering ELAI uses in its gate stack.
