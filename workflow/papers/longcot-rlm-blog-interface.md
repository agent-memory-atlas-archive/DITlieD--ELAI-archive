Core Thesis:
An informal empirical exercise supporting the Mismanaged Geniuses Hypothesis. Author argues frontier models are significantly more capable than benchmarks suggest, and that the inhibitor is how models are used, not what they can do.

Benchmark: LongCoT (Motwani et al. 2026)
- 500 problems across 5 domains: MATH, CHEM, CS, LOGIC, CHESS
- Problems are structured as directed acyclic graphs; each node is a sub-problem with dependencies
- Evaluated on LongCoT-mini subset (500 problems)

Harness: DSPy.RLM (implementation by Raymond Weitekamp)
- RLM = Recursive Language Model scaffold; tasks decomposed recursively via code execution and sub-calls
- Not a fine-tuned model; pure prompting/scaffolding change at inference time

Model under test: GPT-5.2 (frontier model at time of writing; not an open model)

MEASURED RESULTS (single run each; no error bars reported):

Baseline:
  GPT-5.2 base (no RLM): 38.7% overall on LongCoT-mini
    Breakdown: MATH 26.0%, CHEM 37.0%, CS 40.4%, LOGIC 53.6%, CHESS 36.6%

Initial RLM (DSPy.RLM, no prompt engineering):
  RLM(GPT-5.2) original: 50.6% overall
    Breakdown: MATH 5.6%, CHEM 50.0%, CS 11.0%, LOGIC 86.7%, CHESS 93.0%
  NOTE: MATH degraded from 26.0% (base) to 5.6% (RLM original) -- RLM hurt MATH
  NOTE: CS degraded from 40.4% (base) to 11.0% (RLM original) -- RLM hurt CS

Author intervention:
  - Manually examined RLM execution traces
  - Found: RLMs attempted brute-force approaches that crashed the REPL; sub-agents not verifying sub-problem solutions
  - Diagnosis: "decision-making problems in prompting rather than fundamental capability limitations"
  - Fix: prompted Claude Code to generate strategic tips for avoiding mistakes; injected tips into RLM system prompt
  NOTE: the improved prompt was GENERATED BY CLAUDE CODE (a different model), not hand-authored by the researcher

Enhanced RLM (after prompt injection):
  RLM(GPT-5.2) enhanced: 65.6% overall
    Per-domain breakdowns for enhanced version: listed as "Improved" in source (exact per-domain numbers NOT provided)
  With partial credit: >70%

Summary delta vs baseline:
  GPT-5.2 base: 38.7%
  RLM original: 50.6% (+11.9pp, but harms MATH and CS)
  RLM enhanced: 65.6% (+26.9pp over base, +15.0pp over original)

Key Findings (author's interpretation -- AUTHOR CLAIMS):
1. Strategic prompting substantially improved RLM performance without retraining
2. Models can recognize necessary decomposition strategies (evidenced by Claude Code generating the fix prompt)
3. Suggested training approach: gradually remove prompting scaffolds during post-training rather than relying on pure RL

UNVERIFIED CLAIMS:
- "Frontier language models are significantly more capable than benchmarks suggest" -- the experiment shows prompting improves RLM on LongCoT; it does not bound total capability gap
- "Models possess capabilities inhibited by poor guidance" -- inference from a single prompting intervention, not a controlled study
- Exact per-domain breakdown for enhanced RLM not given (only "Improved" for each domain)
- No information on number of runs, variance, or statistical significance
- GPT-5.2 model identity: not a publicly released model name at the time of this summary; reliability of this identifier is UNVERIFIED
