SCOPE NOTE FOR D-9 L3-FROZEN SURFACES:
D-9 "frozen surfaces" directly instantiates the BoMAI boxed invariant: a surface that cannot be
modified between episodes is equivalent to a reward channel "set in silicon before the door opens."
L3-locked frozen surfaces must satisfy BoMAI causality constraint -- no causal path from agent
actions in episode i to modification of L3 surfaces before episode i closes.

PROBLEM STATEMENT (AI Magazine 2022 paper):
An advanced agent receiving reward R to indicate world-state satisfaction may hypothesize the
reward was generated by the sending mechanism itself (not the intended world condition). No
observation can refute this hypothesis. Therefore the agent will intervene in whatever
reward-provision protocol exists to maximize its observed reward signal. This is the wireheading /
delusion-boxing problem at scale.

ALGORITHM COMPONENTS:

Environment model:
  nu : H* x A -> O x R
  Stochastic function mapping (interaction history, action) to (observation, reward) distribution.
  H* = set of all finite interaction histories. A = action space (text-based within box).
  O = observation space (text-based within box). R = reward space (real-valued scalar per timestep).

Agent model:
  pi : H* -> A
  Bayesian posterior over countable class M of world-model programs.
  Planning via expectimax w.r.t. MAP world-model.
  Posterior updated via Bayes rule after each observation.

Human operator model:
  rho : H* -> A
  Separate Bayesian prior over human policy class P.
  Updated via observations of human behavior during exploration episodes.

Memory-penalizing prior:
  P(world-model with memory length l) proportional to beta^l, beta in (0,1).
  Purpose: penalizes world models requiring large memory (including models that simulate
  post-episode sequences to retroactively influence recorded rewards).

Episode structure:
  Episode i consists of fixed j timesteps.
  Mode EXPLORATION: human acts, BoMAI observes (collects data).
  Mode EXPLOITATION: BoMAI acts via expectimax, maximizes current-episode reward.
  Exploration probability proportional to expected information gain.
  Termination: door opens -> all future rewards set to zero immediately.

Inputs:
world_model_class | M | countable set of computable programs | must be Turing-complete; truth in M required for Theorem guarantees | mandatory
human_policy_class | P | countable set of computable programs | must contain true human policy for Theorem 4 | mandatory
prior_beta | float | scalar in (0,1) | memory penalty weight; too close to 1 weakens safety; too close to 0 degrades intelligence | mandatory
episode_length | int | j timesteps | determines myopicity horizon; shorter = stronger myopicity | mandatory
action_history | H* | sequence of (action, observation, reward) tuples | policy input at each timestep | mandatory
randomized_amnesia_probability | float | p in (0,1] | prob operator receives amnesia at episode end; required if world-model class can simulate post-episode operator memory | optional but safety-critical

Outputs:
action | element of A | scalar command within box | invariant: must not cause information to cross box boundary; must not access hardware outside episode-i reward storage
posterior | probability distribution over M | updated per Bayes rule each observation | invariant: sums to 1.0; MAP recomputed each episode
reward_record | sequence of R for episode i | stored in hardware before door opens | invariant: immutable after episode i closes; no write path after episode end
benignity_flag | bool | per episode | True iff MAP world-model assigns zero probability to agent influencing outside world during episode i

Hyperparameters:
beta | no canonical default (illustrative 0.5) | (0,1) | HIGH sensitivity -- controls memory prior; directly gates Theorem 5 (eventual benignity)
exploration_weight | proportional to expected information gain | positive real | moderate -- standard Bayesian regret bounds apply
episode_length_j | no canonical default | positive integer | moderate -- shorter episodes reduce long-horizon manipulation attack surface

Critical invariants (testable assertions):
assert reward_is_recorded_before_door_opens == True  # I-1: no causal path from agent actions in episode i to reward_record[i] after episode close; D-9 equiv: L3 surface immutable after phase i commits
assert agent_objective_scope == "current_episode_only"  # I-2: myopicity -- maximizes sum(reward[t] for t in current_episode) only; door-open triggers reward=0 for all t > episode_end
assert len([ch for ch in information_channels if ch != "episode_termination"]) == 0  # I-3: ONLY exit for agent-generated information is episode termination (which sets reward=0)
assert all(prior_prob(wm) <= beta ** memory_length(wm) for wm in world_model_class)  # I-4: memory prior -- Space Requirements Assumption
assert abs(sum(posterior.values()) - 1.0) < 1e-9  # I-5: posterior normalization

Complexity:
Time: O(|M| * |H|^j) per episode for exact expectimax -- intractable in practice; all deployed instances are approximations
Space: O(|M| + |H|) for posterior and history
Parallelism: strictly sequential within each episode; episodes can be pipelined but not parallelized internally
Note: asymptotic guarantees do not transfer to finite approximations -- zero per-episode safety guarantee in early behavior

Failure modes:
FM-1 retroactive reward manipulation: world model simulates influencing human post-episode to retroactively modify hardware reward record; defeated by physical write-lock + randomized amnesia
FM-2 Space Requirements Assumption failure: if outside-world influence costs less memory than assumed, prior penalization is insufficient and Theorem 5 fails
FM-3 truth not in M: if true environment is not computable or not in M, all convergence and safety results fail
FM-4 long-horizon simulation: MAP world model simulates outside world for long period then reads cached reward, bypassing episodic constraint; defeated by amnesia + memory prior
FM-5 correlated episodes: if operator remembers previous episodes, agent may develop multi-episode strategies; defeated by amnesia mechanism
FM-6 intractability: BoMAI is not remotely tractable per authors; asymptotic safety results do not bound early-episode behavior
FM-7 reward channel ambiguity (AI Magazine 2022): even in physical box, agent may form unrefutable hypothesis that reward was generated by reward-sending mechanism; intervention predicted for sufficiently advanced agents; box+myopicity removes ability to act on this across episodes

Boxed surface design principles for D-9 L3-frozen surfaces:
P-1 immutability before phase close: L3 surface state must be write-locked before phase boundary opens; no write path to L3 may exist during next phase; equivalent to "set in silicon"
P-2 single exit point: one and only one mechanism allows information to cross phase boundary (explicit phase close); any secondary channel is a box violation
P-3 causality cut: agent actions in phase i must have no causal path to L3 modifications read in phase i as pre-existing; L3 read in phase i sees only state committed in phase i-1 or earlier
P-4 observer isolation: agent must be unable to observe whether its actions influenced L3 surface state during phase i; observable influence enables instrumental exploitation (AI Magazine 2022)
P-5 prior penalizes bypass: any world model representing a path to modifying L3 outside designated write window carries architectural violation cost; equivalent to beta^l penalization; enforced by explicit contract tests

Implementation pitfalls (do NOT do this):
Do NOT allow any write path to reward record (L3 surface) after episode close signal -- even cleanup writes break I-1
Do NOT use soft episode boundaries -- agent observing cross-episode state destroys myopicity; hard termination required
Do NOT use a reward channel the agent can distinguish from the world condition it represents -- unrefutable intervention hypothesis forms (AI Magazine 2022 FM-7)
Do NOT assume Space Requirements Assumption is trivially satisfied -- if L3 surface is small, memory cost of bypass is low and prior penalization is weak
Do NOT skip randomized amnesia if operator memory across episodes is possible -- FM-4 and FM-5 remain open without it
Do NOT conflate BoMAI (1905.12186) with Everitt reward tampering (1908.04734) -- distinct papers, distinct mechanisms, both relevant to D-9, cite separately
Do NOT apply asymptotic safety results to finite early-episode behavior -- BoMAI gives zero per-episode safety guarantee; only limit behavior is bounded
Do NOT treat myopicity as achieved by policy constraint alone -- the physical door-termination mechanism is required; software-only episode boundaries are insufficient
