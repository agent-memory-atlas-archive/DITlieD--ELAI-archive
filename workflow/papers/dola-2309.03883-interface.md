Algorithm: DoLa (Decoding by Contrasting Layers)
ArXiv: 2309.03883
Paper: DoLa: Decoding by Contrasting Layers Improves Factuality in Large Language Models
Venue: ICLR 2024
Authors: Yung-Sung Chuang, Yujia Xie, Hongyin Luo, Yoon Kim, James Glass, Pengcheng He

Inputs:
token_ids          | List[int]     | shape (seq_len,)        | mandatory; prompt tokens fed to the model
model_hidden_states| Tensor        | shape (N+1, seq_len, d) | mandatory; all layer hidden states from one forward pass (layer 0 through N)
final_layer_logits | Tensor        | shape (vocab_size,)     | mandatory; logits from layer N (standard output); derived from model_hidden_states[-1]
candidate_layer_set| List[int]     | subset of [0..N-1]      | mandatory; even-indexed layers within configured buckets; paper uses even-only for efficiency
alpha              | float         | scalar, default 0.1     | optional; plausibility threshold for V_head constraint (Section 3.5)
theta              | float         | scalar, default 1.2     | optional; repetition penalty coefficient (Section 4/Algorithm 1 step 8)

Outputs:
next_token_logits  | Tensor        | shape (vocab_size,)     | contrastive log-ratio scores; -inf for tokens not in V_head; valid tokens satisfy log(q_N(x)/q_M(x))
selected_premature_layer | int     | scalar in candidate_layer_set | the j that maximizes JSD(q_N || q_j) for this token position
next_token_id      | int           | scalar                  | argmax or sampled from softmax(next_token_logits)

Invariants on outputs:
- V_head is always a subset of the full vocabulary: len(V_head) <= vocab_size
- tokens outside V_head receive logit value of -inf (not a large negative float — true -inf)
- JSD is symmetric and bounded: 0.0 <= JSD(p||q) <= log(2) in nats; paper scales by 10^5 for display only
- selected_premature_layer is always drawn from candidate_layer_set, never from [N] (the final layer)
- after softmax over next_token_logits, resulting distribution sums to 1.0 over V_head tokens

Hyperparameters:
alpha              | 0.1     | (0.0, 1.0)  | plausibility threshold; lower = more tokens pass filter; paper fixes at 0.1 without sensitivity sweep
theta              | 1.2     | [1.0, 2.0)  | repetition penalty; DoLa benefits from moderate penalty; CD and baseline do not — see Figure 11/12
bucket_config      | model-size-dependent | see below | low sensitivity within bucket; high sensitivity to wrong bucket boundary
temperature        | 0.7     | (0.0, 2.0]  | used for Vicuna sampling only; greedy elsewhere

Bucket configuration (number of transformer layers N):
N=32  (7B):  2 buckets [0,16), [16,32) — candidate layers are even indices within lower bucket for each phase
N=40  (13B): 2 buckets [0,20), [20,40)
N=60  (33B): 3 buckets [0,20), [20,40), [40,60)
N=80  (65B): 4 buckets [0,20), [20,40), [40,60), [60,80)
Candidate set J uses even-indexed layers within the relevant bucket only.

Critical invariants (testable assertions):
assert 0.0 <= jsd_value <= 1.0 + 1e-6  # JSD in nats bounded by log(2)~=0.693; in bits bounded by 1.0; must not be negative
assert selected_layer in candidate_layer_set  # premature layer must come from J, not from final layer N
assert selected_layer != N  # contrasting with self is undefined and must be excluded
assert all(q_N[v] >= alpha * q_N.max() for v in V_head)  # V_head definition (Section 3.5, Eq for adaptive plausibility)
assert abs(softmax(contrastive_logits[V_head]).sum() - 1.0) < 1e-5  # output distribution normalizes over V_head
assert sum(1 for x in contrastive_logits if x != float('-inf')) == len(V_head)  # tokens outside V_head are exactly -inf

Complexity:
Time per token | O(N * d * vocab) for N forward passes if naive; O(d * vocab * |J|) if only candidate layers are materialized | parallelizable across J within a single forward pass
Space per token | O(|J| * d) for storing intermediate hidden states | must hold all candidate layer activations simultaneously; not streaming-compatible
Parallelism     | all J candidate layers computed in one forward pass (no sequential dependency across layers in forward); JSD selection is sequential after forward pass
Overhead vs baseline | 1.06x-1.08x latency, 0.93x-0.95x throughput (measured on V100, 16-bit float, batch=1); +0.6% to +1.1% memory

Failure modes:
Small models (<1B, e.g. GPT2-Medium 335M): DoLa degrades performance. MC1 drops 23.5->22.9, FACTOR-News 41.0->22.2. Root cause: model too small to develop distinct layer representations for factual vs syntactic knowledge.
Static layer selection: optimal premature layer is inconsistent across validation splits (e.g., layer 10 optimal on GSM8K subset#1, layer 2 on subset#2 for LLaMA-7B). Static selection is unreliable; dynamic JSD is load-bearing.
Random layer selection: FACTOR-News 13B drops to 53.8 vs 62.5 for DoLa. JSD maximization is not replaceable with uniform random selection from J.
Wrong bucket boundary: using upper-layer bucket [16,32) instead of lower [0,16) for 7B on FACTOR-News causes accuracy drop from ~0.62 to ~0.47 (Figure 8 analog for 13B).
Softmax before log-ratio: applying softmax to logits before computing log(q_N/q_M) reduces MC2 from 63.8 to 52.2 on LLaMA-7B TruthfulQA. The raw (unnormalized) log-ratio variant is strictly better.
Contrastive Decoding with amateur model: CD with a smaller model (e.g. LLaMA-7B as amateur for 13B expert) can collapse reasoning — GSM8K 13B drops from 16.68 to 9.10. DoLa avoids this by staying within the same model.

Implementation pitfalls (do NOT do this):
Do NOT apply softmax to intermediate layer logits before computing the log-ratio; use raw logit ratio log(q_N(x)/q_M(x)) directly (ablation Section 8.2 shows -11.6 MC2 penalty for softmax variant).
Do NOT use odd-indexed layers in candidate set J; paper restricts to even-indexed layers for efficiency and consistency.
Do NOT include the final layer N in the candidate set J; contrasting a layer with itself produces JSD=0 and undefined log(1)=0 contrast.
Do NOT set V_head tokens to large negative float (e.g. -1e9); use true float('-inf') to ensure they contribute zero probability after softmax.
Do NOT select the premature layer globally (once per sequence); selection is per-token — different tokens require different premature layers (Figure 3 and NER analysis).
Do NOT use DoLa with models below ~7B parameters; empirical evidence shows degradation on GPT2-Medium (335M).
Do NOT skip the adaptive plausibility constraint (V_head filter); without it, the log-ratio can boost noise tokens that the final layer assigns near-zero probability.
Do NOT use a single bucket spanning the full layer range [0,N) uniformly; bucket boundaries are calibrated per model size and matter for performance.
