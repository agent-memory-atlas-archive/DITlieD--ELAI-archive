DoLa: Decoding by Contrasting Layers Improves Factuality in Large Language Models
arxiv: 2309.03883 | ICLR 2024 Main Conference
Authors: Yung-Sung Chuang, Yujia Xie, Hongyin Luo, Yoon Kim, James Glass, Pengcheng He
Submitted: 2023-09-07 (v1), Revised: 2024-03-11 (v2)
Categories: cs.CL, cs.AI, cs.LG


1. PROBLEM

LLMs hallucinate — generating plausible but factually incorrect text. Existing mitigations require either external knowledge retrieval or fine-tuning. The paper targets a training-free, inference-only approach.


2. CORE INSIGHT

Factual knowledge emerges progressively through transformer layers. Early layers encode syntactic/structural patterns; later layers incorporate factual associations. For a question like "What is the capital of Washington State?", the incorrect but popular answer "Seattle" maintains high probability across all layers, while the correct answer "Olympia" only gains probability in deeper layers. By contrasting early vs. late layer distributions, the factual signal can be amplified.


3. METHOD

3.1 Standard next-token prediction
  p(x_t | x_{<t}) = softmax(phi(h_t^{(N)}))_{x_t}
  where h_t^{(N)} is the hidden state at final layer N, phi is the vocabulary projection head.

3.2 Early-exit distributions
  q_j(x_t | x_{<t}) = softmax(phi(h_t^{(j)}))_{x_t}  for j in J
  J = set of candidate premature layers (even-indexed only, for efficiency).

3.3 Dynamic premature layer selection
  M = argmax_{j in J} JSD(q_N(. | x_{<t}) || q_j(. | x_{<t}))
  For each token, select the premature layer M that has maximum Jensen-Shannon Divergence from the final layer. This identifies where the model's representation changed most — i.e., where factual knowledge was injected.

3.4 Contrastive decoding
  p_hat(x_t | x_{<t}) = softmax(F(q_N(x_t), q_M(x_t)))_{x_t}
  where F = log(q_N(x_t) / q_M(x_t)) if x_t in V_head, else -inf

3.5 Adaptive plausibility constraint
  V_head(x_t | x_{<t}) = {x_t in X : q_N(x_t) >= alpha * max_w q_N(w)}
  alpha = 0.1. Filters out tokens the final layer considers implausible, preventing the contrast from boosting noise.

3.6 Candidate layer buckets (model-specific)
  7B  (32 layers): 2 buckets [0,16), [16,32)
  13B (40 layers): 2 buckets [0,20), [20,40)
  33B (60 layers): 3 buckets [0,20), [20,40), [40,60)
  65B (80 layers): 4 buckets [0,20), [20,40), [40,60), [60,80)


4. ALGORITHM (Algorithm 1)

Input: tokens {x_1, ..., x_{t-1}}, model with N layers, candidate set J
1. Embed tokens through layer 0
2. Forward-propagate to compute hidden states H_j at each layer j
3. Compute distributions q_j at all candidate layers J and final layer N
4. Select premature layer: M = argmax_{j in J} JSD(q_N || q_j)
5. Compute adaptive plausibility set: V_head = {x : q_N(x) >= 0.1 * max q_N}
6. Contrast logits: for valid tokens, compute log(q_N(x) / q_M(x)); set -inf for rest
7. Apply softmax to get final distribution p_hat
8. Sample or greedily decode next token; optionally apply repetition penalty (theta=1.2)
9. Repeat until sequence end


5. EXPERIMENTAL SETUP

Models: LLaMA 7B/13B/33B/65B, MPT-7B, GPT2-Medium (335M)
Hardware: NVIDIA V100 GPUs (2/4/8 for 13B/33B/65B), 40-core Intel Xeon @ 2.70GHz
Precision: 16-bit float, batch size 1

Datasets and metrics:
  TruthfulQA: MC1, MC2, MC3 (multiple choice); %Truth, %Info, %T*I, %Reject (open-ended)
  FACTOR: News/Wiki subsets (long-paragraph factuality)
  StrategyQA: multi-hop reasoning accuracy (chain-of-thought)
  GSM8K: math word problem accuracy
  Vicuna QA: GPT-4 pairwise evaluation

Hyperparameters: alpha=0.1, theta=1.2 (repetition penalty), temperature=0.7 (sampling), max_tokens=1024 (Vicuna)

Baselines:
  Standard decoding (greedy/sampling)
  Contrastive Decoding (CD, Li et al. 2022) — uses a smaller amateur model
  Inference-Time Intervention (ITI, Li et al. 2023) — trained classifier on TruthfulQA
  Random layer selection (ablation)
  DoLa-static (fixed premature layer)

Validation: 2-fold for TruthfulQA/FACTOR; 10% random GSM8K subset for StrategyQA/GSM8K

8. ABLATIONS

8.1 Dynamic vs Static layer selection
DoLa-static performance varies across validation folds. On GSM8K 7B, optimal layer differs between subset#1 (layer 10) and subset#2 (layer 2). Dynamic DoLa is robust across both. Same pattern at all model scales on FACTOR-News.

8.2 Softmax variants (LLaMA-7B on TruthfulQA)
  Vanilla:           MC1=25.6, MC2=40.6, MC3=19.2
  DoLa w/ softmax:   MC1=31.9, MC2=52.2, MC3=28.2
  DoLa w/o softmax:  MC1=32.2, MC2=63.8, MC3=32.1
Without softmax normalization before log-ratio gives better results (preserves sharper contrast).

8.3 Contrasting strategy variants (LLaMA-7B)
  Vanilla:         MC1=25.6, MC2=40.6, MC3=19.2
  DoLa 0th layer:  MC1=31.6, MC2=61.7, MC3=30.1
  DoLa all layers: MC1=32.0, MC2=63.9, MC3=31.2
  DoLa (dynamic):  MC1=32.2, MC2=63.8, MC3=32.1
All contrasting approaches beat vanilla substantially. Dynamic is best or tied-best.

8.4 CD baseline comparison (GSM8K)
CD with amateur model often hurts (e.g., CD w/LLaMA-7B on 13B: 16.68 -> 9.10). DoLa avoids this because it contrasts within the same model.

8.5 NER critical layer distribution
On CoNLL-2003 NER dataset, entity tokens select higher premature layers vs non-entity tokens:
  Layer 0:  entity=35.56%, non-entity=75.55%
  Layer 22: entity=9.69%, non-entity=1.76%
  Layer 24: entity=10.38%, non-entity=2.62%
  Layer 28: entity=10.06%, non-entity=2.11%
  Layer 30: entity=25.40%, non-entity=12.98%
Non-entity tokens (function words) mostly select layer 0 (no factual change needed). Entity tokens distribute across higher layers (factual knowledge added progressively).

8.6 Repetition penalty sensitivity
On StrategyQA and GSM8K, DoLa benefits from repetition penalty (theta=1.2) while CD and baseline show flat or declining performance with increasing penalty. Effect is consistent across model sizes.

8.7 Random layer selection (FACTOR)
Random layer selection within the candidate set gives inconsistent results. At 13B, random drops to 53.8 (News) vs 62.5 for DoLa. At 7B, random is 60.0 vs 62.0 for DoLa. Demonstrates that JSD-based selection is load-bearing.

11. RELATED WORK (key connections)

Factual knowledge localization: Dai et al. 2022 (knowledge neurons), Meng et al. 2022 (ROME), show factual associations stored in specific layers/neurons.
Early exit: Elbayad et al. 2020 (depth-adaptive), Schuster et al. 2022 (CALM), Teerapittayanon et al. 2016 (BranchyNet). DoLa uses early-exit distributions differently — for contrast, not efficiency.
Contrastive decoding: Li et al. 2022 (CD with amateur/expert models), Gera et al. 2023 (autocontrastive across layers). DoLa improves on Gera by using dynamic rather than static layer selection.
Retrieval augmentation: Borgeaud et al. 2022 (RETRO), Ram et al. 2023. DoLa is complementary — uses no external knowledge.
ITI: Li et al. 2023. Requires trained probes on TruthfulQA; DoLa is fully unsupervised.


12. LIMITATIONS

1. Focuses exclusively on factuality — not explored for other RLHF dimensions (helpfulness, safety)
2. Inference-only — cannot improve underlying model knowledge; limited by what the model learned
3. No external grounding — cannot correct misinformation acquired during pretraining
4. Requires sufficient model scale (>7B) — degrades on small models (GPT2-Medium shows negative results)
5. The method is complementary to other approaches and could be combined with retrieval/fine-tuning
